첫 공개 이전의 소급 개발 번호는 개별 공개 릴리스가 아니다. 각 구간의 기능 추가/변경·버그/UI 수정과 최종 상태를 함께 설명하고, 과거에 잠시 적용됐다 되돌린 탭/크기를 현재 기능으로 오인하지 않도록 연결했다.

노트 수정 이후에도 공개 당시 패키지 안의 설명/manifest는 보존한다. 그 파일의 notes_sha256은 당시 포장한 설명의 해시이며 이후 GitHub 설명 수정의 해시가 아니다. 변경 전후 확인은 [검증 기록](../../docs/validation.md)을 따른다.

다음 배포는 release/notes.md와 release/notes-range.json을 함께 작성한다. 자세한 기준/검사/설명만 갱신하는 절차는 [배포 가이드](../../docs/release-guide.md)에 있다. 1.1.0–1.1.2는 중간 미게시 버전이며 v1.1.3 누적 노트에 포함했다. 1.1.4는 중간 미게시 버전이며v1.1.5 누적 노트에 포함했다. 1.2.0·1.2.1·1.3.0·1.4.0·1.4.1·1.4.2는 중간 미게시 버전이며v1.4.3 누적 노트에 포함했다. 1.5.0–1.8.3은 중간 미게시 버전이며v1.9.0 누적 노트에 포함했다. 다음 공개 범위의 기준은v1.9.0이다.
