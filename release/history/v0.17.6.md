# Tile Launcher 0.17.6

Option을 누르면 커서 근처에 열리는 macOS용 타일 런처입니다.

- 모든 앱의 최근 창 전환과 앱·폴더 등록
- 앱별 고정 메뉴와 메뉴 막대 자동 수집, 최근·자주 사용 기록
- 집중 모드 필터에 연결하는 프로필과 오버레이 안의 임시 프로필 전환
- 유리·파스텔 / 클래식·직각 테마와 섹션별 색상
- 로그인 시 실행, Dock 항목 가져오기, 고정·이동 가능한 오버레이

업데이트 범위: **v0.17.1 → v0.17.6**. 별도 게시하지 않은 **0.17.2·0.17.3·0.17.4·0.17.5와 0.17.6**의 변경을 모두 포함합니다.

## 이전 공개본 이후의 변경

### 0.17.2 — 즉시 클릭 실행과 설정 이동 수정

- Option을 누른 채 설정/추가 버튼이나 앱·창·메뉴·파일·Finder/휴지통 항목을 클릭하면 즉시 실행합니다. 숫자로 고른 항목만 Option을 놓을 때 실행합니다.
- 클릭/폴더 탐색/설정은 앞선 숫자 선택 대기를 취소해 Option 해제 때 중복 실행하지 않습니다. 고정한 오버레이는 항목 실행 뒤 유지합니다.
- 설정 아이콘/단축키는 일반, 메뉴 +는 현재 앱의 메뉴 추가, 등록 +는 등록 항목·프로필로 이동합니다. 이미 열린 설정 창에도 새 요청을 적용합니다.
- Safari 웹 앱 아이콘을 직접 리소스에서 읽고 앱 실행 API를 분리했습니다. 앱 관리 차단 알림을 진단하고 접근성/앱 관리 설정의 용도와 확인 버튼을 구별했습니다. 앱 업데이트/삭제 기능을 넣은 것은 아니며 알림 해소는 별도 실기 확인 대상입니다.

### 0.17.3 — 메뉴 검색과 추가 팝업 수정

- 수동 메뉴 검색에서도 Apple 시스템 메뉴와 Recent Items 등 하위 항목 전체를 제외합니다. 앱 고유의 동명 명령과 기존 수동 등록은 보존합니다.
- 메뉴 추가 팝업을 부모 설정 창 높이의 대부분으로 키우고 목록이 남은 공간을 쓰게 했습니다. 설정 창 크기와 직접 입력 펼침에 따라 조절합니다.

### 0.17.4 — 설정 잘림과 메뉴 목록 공간 수정

- 일반 설정이 작은 창에서 잘리지 않도록 스크롤과 화면 경계 보정을 적용했습니다.
- 메뉴 추가 버튼을 하단에 고정하고 수집/고정 메뉴 목록에 남는 높이를 배정했습니다. 긴 안내는 펼쳐볼 수 있습니다.
- 이 개발 단계에서 권한을 별도 탭으로 분리했으며, 아래 0.17.5에서 일반 하단으로 다시 통합했습니다.

### 0.17.5 — 권한 일반 통합과 기본 창 크기

- 권한을 일반 하단으로 합치고 일반/모양/메뉴/등록 항목·프로필 네 탭으로 정리했습니다.
- 가로로 남는 공간을 줄이도록 580pt 폭의 세로형 초기 크기로 변경했습니다. 이 단계의 고정 1000pt 높이는 아래 0.17.6에서 내용 측정으로 대체했습니다.
- 창 크기 조절을 유지합니다. 처음/닫은 뒤 다시 열 때 기본 크기를 적용하고, 이미 열린 창의 탭 이동에서는 사용자가 조절한 크기를 유지합니다.

### 0.17.6 — 일반 내용에 맞춘 초기 높이

- 고정 1000pt 높이를 제거하고 실제 일반 내용에 맞춰 창 높이를 정해 버전 아래의 과한 여백을 줄였습니다.
- 작은 화면에서는 작업 영역 안으로 제한하고 스크롤로 권한/버전에 접근할 수 있습니다.
- 메뉴 하단 추가 버튼·가변 목록, 기본 0.6초 재입력 보정과 기존 사용자 설정을 유지합니다.

변경 비교: https://github.com/colaH16/tile-launcher/compare/v0.17.1...v0.17.6

## 설치와 시작

Apple Silicon Mac, macOS 26 이상이 필요합니다. Intel Mac은 이번 파일의 지원 대상이 아닙니다.

1. ZIP을 풀고 **Tile Launcher.app**을 응용 프로그램 폴더로 옮깁니다.
2. 앱을 열고 메뉴 막대의 설정에서 접근성 권한을 허용합니다.
3. Option을 길게 눌러 오버레이를 엽니다. ⌥X로 고정하고 Esc/⌥W/⌘W로 닫습니다.
4. 집중 모드는 앱 설정의 자동 프로필 선택을 켠 뒤 시스템 설정의 앱 필터에서 연결합니다.

설치 안내: https://github.com/colaH16/tile-launcher/blob/main/docs/installation.md

## 지원 범위

- 일반 설정에서 상단 안내 위·권한 박스와 버전 사이·버전 아래 간격이 균일하지 않은 외관 문제는 남아 있습니다. 다음 UI 업데이트에서 조정할 예정입니다.

- **2026-10-13 추가 확인 — Focus 제한:** macOS 27.2 beta에서 현재 ad-hoc 배포본의 Team ID 조회가 실패하며 Focus 필터 로딩이 시간 초과됩니다. 아이콘 파일과 일반 아이콘 로딩은 정상이지만, 유효한 Apple 서명 후 시스템 연결을 재검증해야 합니다. 그동안 앱 안의 수동 프로필 선택·좌우 전환을 사용하세요. 진단: https://github.com/colaH16/tile-launcher/blob/main/docs/focus-diagnostics.md

- 현재 주 검증 환경은 Apple Silicon/macOS 27.2 beta입니다. macOS 26은 최소 실행 대상으로 빌드했으며 별도 실기 검증은 남아 있습니다.
- 메뉴 자동 수집은 실험 기능으로, 앱이 제공하는 접근성 메뉴 정보에 따라 누락될 수 있습니다.
- 다른 데스크탑의 창 구분·전환은 macOS 내부 API를 일부 사용하며 OS 업데이트에 따라 제한될 수 있습니다.
- 집중 모드의 설정 모델/메타데이터는 검증했지만 시스템 필터 전환 전체의 실기 검증은 추가로 필요합니다.
- 입력 문자·클립보드·화면 이미지를 수집하지 않습니다. 설정과 메뉴 사용 기록은 로컬에 저장합니다.

각 파일의 서명·공증 상태는 이 릴리스 설명 앞부분과 release-metadata.json을 확인하세요.
