**Developer ID 서명 및 Apple 공증 완료.**

# Tile Launcher 1.9.0

업데이트 범위: **v1.4.3 → v1.9.0**. 1.5.0·1.5.1·1.6.0·1.7.0·1.8.0·1.8.1·1.8.2·1.8.3·1.9.0의 변경을 모두 포함합니다.

메뉴 타일마다 아이콘을 직접 고를 수 있고, 아이콘이 없으면 단축키나 메뉴 이름을 크게 보여줍니다. 응답하지 않는 앱 때문에 창 선택이 늦어지던 문제를 줄이고 창 목록 조회·메뉴 수집·스크롤·Option 호출을 가볍게 했습니다.

## 이전 공개본 이후의 변경

### 1.9.0 — 모든 앱에 공통으로 제공하는 ‘앱 설정’ 타일

- 앱마다 설정 메뉴를 수집하거나 고정해 둘 필요가 없습니다. 현재 앱에서 표준 `⌘,` 또는 `Settings / Preferences / 설정 / 환경설정` 등의 설정 메뉴를 확인하면 **앱 설정** 공통 타일을 표시합니다. 처음 사용하는 앱에도 같은 규칙을 적용합니다.
- 타일은 앱별 메뉴 뒤의 마지막 행에 고정 메뉴와 같은 **4×2 크기와 강조색**으로 나타납니다. 아이콘은 가운데 세 갈래가 있는 SF Symbol **gear**이며 벡터로 표시합니다.
- 누를 때 현재 대상 앱의 메뉴를 다시 확인해 실행합니다. Tile Launcher 자체 설정이나 Handoff의 다른 앱을 여는 버튼이 아닙니다. 공통 타일은 앱별 저장 목록·사용 기록을 늘리지 않습니다.
- 앱 이름 아래의 메뉴만 확인해 문서 설정·프로젝트 설정과 구별합니다. 설정 메뉴가 없거나 비활성화되어 있거나, 읽지 못했거나 후보가 모호하면 타일을 숨깁니다. 접근성 정보를 제공하지 않는 앱과 비표준 설정 화면까지 지원하는 것은 아닙니다.
- 설정 탐지는 오버레이 준비·열기와 표시 중 활성 앱 전환 때 필요한 앱 하나만 읽습니다. 앱 전체의 메뉴를 계속 순회하지 않습니다.

### 1.8.3 — 느린 응답에도 Handoff 조회가 쌓이지 않도록 개선

- 이전 조회가 끝난 뒤0.4초를 기다려 다음 조회를 시작합니다. Dock 응답이 늦어져도 조회 요청이 대기열에 쌓이지 않습니다.
- 오버레이를 닫으면 다음 조회 예약을 취소합니다. 빠르게 다시 열어도 조회가 중복되거나 이전 화면의 늦은 결과가 반영되지 않습니다.
- Dock 아이콘을 읽다가 응답이 없으면 해당 조회를 중단합니다. Handoff를 누를 때 현재 Dock 항목을 다시 확인하는 동작은 유지합니다.

### 1.8.2 — 메뉴 연결과 실행 대상 안정성

- 같은 제목의 서로 다른 메뉴가 번역을 공유하지 않도록 항목 식별자와 언어별 전체 경로를 저장합니다. 아이콘도 전체 경로로 연결하며 기존 고정 상태와 사용 기록은 유지합니다.
- 언어를 바꿔도 제외한 메뉴를 다시 수집하지 않도록 확인된 번역 경로를 함께 보관합니다. 이전의 제목별 별칭은 안전한 연결 정보로 다시 확인합니다.
- Handoff 타일이 떠 있어도 왼쪽 앱별 메뉴는 원래 앱의 현재 문서에서 실행됩니다.
- 창 정보를 읽다가 통신에 실패하면 남은 조회를 중단하고 최대2번 추가 읽기로 회복을 시도합니다. 메뉴 실행 명령을 자동 반복하지 않습니다.
- 1.8.2에서는 Handoff 확인 주기·기기 전환 처리·메뉴 내용과 타일 배치를 유지했습니다. 확인 주기는1.8.3에서 위와 같이 보완했습니다.

### 1.8.1 — 모양 설정 순서

- 설정 → 모양의 색 섹션을 메뉴 → 최근 창 → **Handoff** → 등록 항목 순서로 바꿔, 최근 창 첫 칸에 나타나는 Handoff 색을 최근 창 바로 아래에서 고를 수 있게 했습니다.

### 1.8.0 — Option 유지와 고정 오버레이의 같은 동작

- Option을 누르고 연 오버레이도 고정한 오버레이처럼 활성 앱·창·메뉴·Handoff가 바뀌면 바로 갱신합니다. Option을 누르고 있다는 이유로 내용을 고정하지 않습니다.
- 숫자키로 고른 뒤 Option을 놓기 전까지(고정 모드의 실행 표시 포함)와 마우스 버튼을 누르고 있는 동안에만 갱신을 미뤄, 고르거나 누른 대상이 바뀌지 않게 합니다.
- Option을 누르고 연 오버레이도 상단의 빈 곳을 드래그해 옮길 수 있습니다. 빠른 재입력으로 다시 열면 옮긴 위치로 엽니다.
- 닫히는 규칙(Option을 놓으면/바깥 클릭/다른 데스크탑으로 이동 시 닫힘, 고정은 ×·Esc·⌘W·⌥W)과 고정 시 키 입력을 받는 동작은 그대로입니다.

### 1.7.0 — Handoff 타일

- iPhone·iPad에서 보던 작업을 Mac에서 이어서 열 수 있을 때(Dock 오른쪽의 Handoff 아이콘), 최근 창의 첫 번째 타일이 같은 크기의 **Handoff** 타일로 바뀝니다. 첫 타일은 원래 지금 보고 있는 창이라 오버레이 배치는 그대로입니다. 열린 창이 없으면 Handoff 타일 하나만 표시합니다.
- 타일에는 이어서 열 Mac 앱의 아이콘과 보낸 기기(iPhone/iPad 등) 배지, 아래에 “Handoff”를 표시합니다. 클릭하거나 ⌥⌘1로 Dock의 Handoff를 누른 것과 같이 엽니다.
- 1.7.0에서는 오버레이가 떠 있는 동안0.5초마다 Dock을 확인했습니다. 이후1.8.3부터 조회 완료 후0.4초 대기로 바뀌었고, Option 유지 중 첫 칸만 갱신하던 방식은1.8.0부터 전체 갱신으로 통일했습니다. 기기에서 앱을 바꾸거나 닫았을 때 Dock 아이콘 자체가 바뀌는 시간은 macOS가 정합니다.
- **설정 → 모양**에 Handoff 색을 추가했습니다(기본 청록). 최근 창 색 예시 이름을 **대표 창**(앱마다 마지막으로 사용한 창)과 **이전 창**(같은 앱의 나머지 창)으로 바꿨습니다.
- Handoff 정보는 macOS 공개 API가 아니라 Dock의 접근성 정보에서 읽습니다. 기존 접근성 권한을 사용하며, macOS 업데이트로 Dock 구조가 바뀌면 동작하지 않을 수 있습니다.

### 1.6.0 — 앱 메뉴 아이콘 자동 저장

- 자동·수동으로 메뉴를 추가하면 앱 리소스에서 메뉴에 연결된 아이콘을 찾아 저장합니다. 없는 경우 이미 읽어 둔 다른 앱의 메뉴에서 가져올 수 있습니다. 현재1.8.2 이후에는 전체 경로가 같고 그림이 충돌하지 않는 후보만 사용합니다.
- **벡터 보존:** SF Symbols는 코드, PDF는 원본 벡터로 저장합니다. 비트맵만 원래 해상도로 저장합니다.
- 앱 업데이트 후에도 저장한 아이콘을 유지합니다. **설정 → 메뉴 → 메뉴 아이콘 새로고침**으로 선택한 앱의 아이콘을 다시 가져올 수 있으며, 직접 지정한 아이콘과 아이콘 없음 선택은 우선합니다.
- **언어가 바뀌어도 같은 메뉴:** 앱의 메뉴 이름을 macOS 선호 언어 전체(시스템 설정 → 언어 및 지역의 목록), 미국 영어, 앱의 기본 언어, 그리고 저장한 메뉴가 쓰인 언어로 함께 저장합니다. 예를 들어 Finder를 영어에서 한국어로 바꿔도 New Tab으로 저장한 메뉴가 ‘새로운 탭’으로 실행되고, 사용 기록·고정·아이콘이 이어집니다. 앱 리소스에 없는 동적 메뉴는 기존처럼 저장한 이름으로만 찾습니다.
- 아이콘과 메뉴 이름 정보는 앱별 파일로 나눠 필요한 언어만 저장해 크기를 줄였습니다(음악 앱 기준 약 296KB → 88KB, 메뉴 이름 정보 포함). 처음 실행 때 기존 메뉴의 앱을 한 번씩 백그라운드에서 읽습니다.
- 메뉴 리소스가 폴더 형태(macOS 버전별 사본)로 들어 있는 앱도 번역을 연결하고 가장 최신 사본 하나만 읽습니다.
- **안정성:** 창 하나를 읽다 응답이 없으면 그 앱의 남은 창 조회를 멈추고 이전 정보를 유지합니다. 메뉴에서 단축키가 없어지면 타일에서도 지우되, 읽기에 실패한 경우에는 기존 단축키를 유지합니다. Option을 누르고 기다리는 동안 미리 만든 오버레이는 표시 직전에 최신 창·앱·메뉴로 갱신합니다.
- 아이콘 선택 화면에서 가져온 앱을 확인할 수 있습니다. 지원되는 정적 메뉴 리소스가 없거나 아이콘을 불러오지 못하면 기본 아이콘·단축키·메뉴 이름 표시를 사용합니다. 모든 앱의 동적 메뉴 아이콘을 지원하는 것은 아닙니다.

### 1.5.1 — 자주 쓰는 메뉴의 기본 아이콘

- New Tab, New Folder, New Window, Get Info, Go to Folder, Connect to Server, Hide/Show Sidebar(한국어 메뉴 이름 포함)는 아이콘을 고르지 않아도 기본 SF Symbol을 표시합니다. 메뉴 이름이 정확히 같을 때만 적용합니다.
- 메뉴 아이콘 선택 화면에 **기본값**(직접 고른 아이콘을 지우고 기본 아이콘 사용)과 **아이콘 없음**(기본 아이콘도 끄고 단축키나 메뉴 이름 표시)을 나눴습니다. 직접 고른 아이콘이 항상 우선합니다.

### 1.5.0 — 메뉴 아이콘 지정과 성능 개선

- **메뉴 아이콘 지정:** 설정 → 메뉴에서 각 메뉴 왼쪽의 버튼을 눌러 SF Symbol 아이콘을 고릅니다. 추천 목록에서 고르거나 SF Symbols 앱의 이름을 붙여 넣을 수 있으며, 이 Mac에 없는 이름은 적용하지 않습니다. 이미지 파일은 지원하지 않습니다.
- **아이콘이 없을 때:** 메뉴에 단축키가 있으면 ⇧⌘G처럼 단축키를 크게 표시합니다. 단축키도 없으면 메뉴 이름을 타일에 크게 쓰고 상위 메뉴를 아래에 작게 표시합니다. 모든 메뉴 타일에 같은 ⌘ 그림이 나오던 방식을 대체합니다.
- 단축키는 메뉴 막대에서 선택할 때, 메뉴 추가 화면에서 불러올 때, Tile Launcher로 메뉴를 실행할 때 앱의 현재 값으로 저장·갱신합니다. macOS 접근성 API가 메뉴 항목의 이미지를 제공하지 않아 1.5.0 당시에는 앱 메뉴의 아이콘을 자동으로 가져오지 않았습니다. 1.6.0부터는 별도의 리소스 분석을 지원합니다.
- **멈춘 앱 대응:** 응답하지 않는 앱의 창 목록은 한 번만 기다리고 이전 목록을 유지합니다. 그동안 다른 창 선택이 몇 초씩 밀리던 경로를 줄였습니다.
- **가벼워진 백그라운드 작업:** 창 상태 조회를 실제 타일이 될 수 있는 창으로 좁히고 창 속성을 한 번에 읽습니다. 메뉴 막대나 열린 메뉴가 아닌 곳의 클릭에서는 메뉴 수집용 조회를 하지 않습니다.
- **더 빠른 표시와 스크롤:** Option을 누르고 기다리는 0.25초 동안 오버레이를 미리 준비합니다. 최근 창을 스크롤할 때 메뉴와 등록 항목을 다시 계산하지 않습니다.
- 타일 크기·색 의미, 개별 창 최근 순서, 등록 항목·프로필과 기존 단축키 동작은 그대로입니다.
