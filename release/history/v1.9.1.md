# Tile Launcher 1.9.1

업데이트 범위: **v1.9.0 → v1.9.1**.

## 이전 공개본 이후의 변경

### 1.9.1 — 공통 앱 설정 타일 표시 선택

- **설정 → 메뉴** 맨 위의 **공통 메뉴** 구역에 **앱 설정 타일 표시** 옵션을 추가했습니다. 자동 메뉴 수집과 별개로 전체 앱에 적용합니다.
- 기본값은 켜짐입니다. 끄면 공통 앱 설정 타일을 숨기고 해당 메뉴 탐지도 멈춥니다. 다시 켜면 설정 메뉴를 지원하는 앱에 표시합니다.
- 선택은 앱을 다시 실행해도 유지합니다. 숨긴 타일은 오버레이 행 수와 높이 계산에서도 제외하며, 기존 앱별 고정 메뉴·사용 기록·자동 수집 설정은 유지합니다.
