# Tile Launcher 1.4.3

업데이트 범위: **v1.1.5 → v1.4.3**. 중간 버전 1.2.0·1.2.1·1.3.0·1.4.0·1.4.1·1.4.2와 이번 1.4.3의 변경을 모두 포함합니다.

현재 버전은 **개별 창의 최근 사용 순서**, **데스크탑 위치에 따른 타일 크기**, **앱의 첫 등장 여부에 따른 색상**을 사용합니다. 타일은 최대 1.4배로 키우되 상하단과 바깥 여백은 확대하지 않습니다. 아래의 1.2.0 앱 묶음 정렬은 1.3.0에서 개별 창 정렬로 대체됐고, 1.4.1의 1.3배 타일은 이번 1.4.3에서 다시 1.4배로 조정됐습니다.

## 이전 공개본 이후의 변경

### 1.4.3 — 타일 1.4배와 간결한 상하단

- 타일과 타일 안의 글자·아이콘을 최대 1.4배로 표시합니다. 바깥 여백, 영역 사이 간격, 상하단, 버튼과 제목은 함께 키우지 않습니다. 타일 사이 간격도 이전 1.3배 수준을 유지합니다.
- 상단을 **앱 아이콘 · 앱 이름 — 창 이름** 한 줄로 바꾸고 아이콘과 글자를 키웠습니다. 제목을 조금 내려 위아래 여백이 균형 있게 보이도록 맞췄습니다. 긴 앱 이름과 창 이름은 모두 한 줄로 줄여 표시하며 전체 이름은 툴팁으로 확인할 수 있습니다.
- 하단 안내 아래 여백을 8pt, 좌우 여백을 24pt로 맞췄습니다. 실제 창 높이 계산에도 같은 값을 적용해 줄인 공간이 다시 빈칸으로 남지 않도록 했습니다.
- 프로필별 높이 조절, 작은 화면에서의 목록 배분, 빠른 Option 재입력 시 위치 복원과 기존 실행 동작을 유지합니다.

### 1.4.2 — 내용에 맞는 목록 높이와 기본 크기 컨트롤

- 메뉴와 최근 창을 실제 타일 크기로 배치한 뒤 더 긴 목록에 맞춰 높이를 정합니다. 한 줄이면 1줄, 두 줄이면 2줄, 세 줄이면 3줄을 표시하고, 네 줄 이상일 때만 3.3줄로 다음 줄을 살짝 보여줍니다. 전체 오버레이 높이도 함께 조절됩니다.
- 핀·닫기·설정·뒤로 버튼을 기본 Glass 스타일의 32pt 크기로 맞추고 헤더를 52pt로 줄였습니다. 섹션 제목·프로필·하단 안내·창 모서리도 타일 배율과 분리했습니다.
- 확보한 공간을 최근 창과 등록 목록에 배분합니다. 작은 화면에서는 두 영역의 높이를 조절하며, 표시 영역을 넘는 항목은 스크롤로 접근할 수 있습니다.

### 1.4.1 — 등록 목록 잘림과 확대된 여백 수정

- 등록 앱이 39개인데 한 줄만 보이고 아래에는 빈 공간이 남던 높이 계산을 수정했습니다. 남은 높이를 정수 행으로 버리지 않고 목록에 사용합니다.
- 당시 기본 배율을 1.4배에서 1.3배로 낮추고, 바깥 24pt 여백과 영역 사이 간격·상단 공간은 함께 확대하지 않도록 분리했습니다.
- 화면이 작은 경우 최근 창 영역을 조금 줄여 등록 목록에 공간을 확보합니다. 프로필을 바꾸거나 오버레이를 다시 열 때도 화면 경계 안에서 크기를 맞춥니다.

### 1.4.0 — 앱 실행 피드백, 설정 정리와 데스크탑 전환 보완

- 앱 실행을 요청하면 대기 표시를 띄우고 같은 앱의 중복 실행을 막습니다. 3초 안에 실행 시작을 확인하지 못하면 해제하고, 시작됐다면 macOS의 실행 완료 신호까지 기다립니다. 오류·종료 시에는 즉시, 완료 신호가 없는 경우에는 최대 60초 후 해제합니다. 다른 앱과 창은 계속 선택할 수 있습니다.
- 숫자 단축키 선택에 눌림 표시와 선택한 이름을 추가했습니다. 고정 모드에서는 실행 요청 뒤에도 잠깐 타일을 강조하고, 일반 모드에서는 Option을 놓으면 실행과 함께 닫힙니다.
- 최근 창 위의 긴 색 설명을 타일 모양과 ‘현재 모니터 / 다른 모니터 / 안 보임’ 안내로 바꿨습니다. 크기와 색의 자세한 기준은 일반 설정에서 확인할 수 있습니다.
- 설정 설명을 줄이고 기본 창 높이를 일반 탭 전체 내용에 맞췄습니다. 네 탭의 상단·좌우 여백과 정렬, 메뉴 목록의 가변 높이와 하단 ‘메뉴 추가’ 버튼도 함께 정리했습니다. 수동 창 크기 조절은 유지합니다.
- 다른 데스크탑 창을 기존 화면 위에 겹쳐 보이게 할 수 있는 직접 Space 변경 호출을 제거하고 macOS의 앱·창 활성화 경로를 사용합니다. 대상 창의 포커스를 확인하고 실패하면 오류를 알려줍니다. 사용자가 보고한 겹침 현상의 실제 환경 해결 여부는 아직 확인되지 않았습니다.

### 1.3.0 — 개별 창 최근 순서와 위치별 타일

- 같은 앱의 모든 창을 한꺼번에 앞으로 모으던 방식을 **각 창을 최근 활성화한 순서**로 바꿨습니다. 목록에서 앱의 첫 실제 창은 진한색, 이후 같은 앱의 창은 파스텔이며 연속해서 나오지 않아도 적용합니다. 창 없는 실행 중 앱은 회색 1×1입니다.
- 활성 앱의 가장 최근 보이는 창이 있는 모니터의 현재 데스크탑 창은 **4×2**, 다른 모니터의 보이는 데스크탑 창은 **2×2**, 보이지 않는 데스크탑 창은 **1×1**로 표시합니다. 크기는 위치, 색은 앱 첫 등장 여부를 나타냅니다.
- 두 모니터에 걸친 창은 겹치는 면적이 큰 모니터를 기준으로 합니다. 모니터 정보가 부족한 보이는 창은 2×2, 위치도 확인되지 않는 창은 1×1로 표시하고 툴팁으로 구분합니다.
- 확대 후 글자가 번지던 문제를 개선했습니다. 전체 화면에 확대 변환을 거는 대신 글꼴·아이콘·타일을 최종 크기로 그립니다.
- 설정 설명과 색 예시를 새 규칙에 맞췄습니다. 작은 타일을 세로로 두 개씩 배치하는 방식과 표시 중 번호 고정, 프로필·메뉴·앱 종료 기능은 유지합니다.

### 1.2.1 — 큰 아이콘과 왼쪽 아래 제목

- 앱 아이콘 비율을 키우고 메뉴·창·등록 타일의 제목을 왼쪽 아래에 한 줄로 배치했습니다. 긴 제목은 줄여 표시하며 전체 이름은 툴팁과 접근성 이름으로 제공합니다.
- 1.2.0의 앱 묶음 배치를 유지하면서 오버레이를 최대 1.4배로 확대했습니다. 이때의 전체 확대 방식은 1.3.0에서 실제 크기로 그리는 방식으로 개선됐습니다.
- 화면 작업 영역에 맞춰 배율과 높이를 제한하고, 프로필 전환 시 윗변과 위치를 유지했습니다. 헤더의 드래그 영역이 버튼을 가리지 않도록 하고 유리 테마의 작은 타일에서 하단 제목이 잘리지 않게 조정했습니다.

### 1.2.0 — 앱별 창 묶기 도입

- 같은 앱의 창을 최근 사용 순서의 묶음으로 모으고 활성 앱 묶음을 맨 앞에 표시했습니다. 묶음 안에서도 타일은 각각의 창을 선택합니다. 이 정렬 방식은 1.3.0에서 개별 창 정렬로 대체됐습니다.
- 활성 앱의 현재 보이는 대표 창 하나는 4×2, 그 밖의 보이는 창은 2×2, 다른 데스크탑이나 위치를 확인할 수 없는 창은 제목이 있는 1×1로 구분했습니다.
- 모든 모니터의 보이는 데스크탑을 진한색으로, 다른 데스크탑을 파스텔로 표시했습니다. 이 색 기준은 1.3.0에서 앱의 첫 등장 여부로 바뀌었습니다. 창 없는 앱의 회색 표시는 유지됩니다.
- 고정 상태에서는 활성 앱 변경을 따라 묶음을 갱신하고, Option을 누르는 동안에는 표시 순서·번호·크기를 유지했습니다. 전체 목록 스크롤과 프로필별 높이, 메뉴·등록 항목 설정도 유지했습니다.

## 설치와 검증

**Apple Silicon · macOS 26 이상**을 지원하며, 주 검증 환경은 macOS 27.2 beta입니다. 단위 검사 157개와 배포 검사 23개, 실제 서명 실행 파일의 화면 없는 UI 렌더링 및 ZIP 검증을 통과했습니다. 같은 39개 등록 항목 샘플에서 선택한 1.4배 시안과 실제 앱의 렌더가 일치하는 것을 확인했습니다.

접근성 권한은 사용자가 직접 허용해야 합니다. 앱의 접근성 지원과 macOS 버전에 따라 창 제어나 데스크탑 전환이 제한될 수 있습니다. Aside의 일시적인 누락 보고는 재현되지 않아 해결 항목에 포함하지 않았습니다.
