# Tile Launcher 1.9.2

업데이트 범위: **v1.9.1 → v1.9.2**.

## 이전 공개본 이후의 변경

### 1.9.2 — Help 검색 수집 수정·탭별 저장과 변경 취소

- iTerm 등 macOS의 **Help → Search**에서 메뉴 검색 결과를 마우스로 클릭했을 때 자동 수집되지 않던 문제를 수정했습니다. 일반 메뉴 클릭과 Enter 선택은 기존 동작을 유지합니다.
- 검색 결과의 글자·아이콘·행 안쪽을 클릭하면 실제 앱 메뉴 경로로 연결합니다. 클릭을 취소하거나 행 밖에서 마우스를 놓은 경우는 수집하지 않습니다.
- 상위 메뉴가 붙은 검색 결과도 경로를 대조하며, 같은 이름 때문에 대상을 하나로 확인할 수 없으면 저장하지 않습니다. 검색 입력 내용이나 일반 앱의 표·본문은 읽어 저장하지 않습니다.

- **모양·메뉴·등록 항목/프로필** 탭마다 **저장 / 변경 취소**를 추가했습니다. 탭을 옮겨도 미저장 편집은 유지하고, 저장한 탭만 실제 오버레이에 반영합니다. 일반 설정은 실시간 저장을 유지합니다.
- **Dock에서 가져오기**를 누르면 목록과 순서를 먼저 보여줍니다. 확인한 목록도 등록 탭의 편집본에만 넣으며, 해당 탭에서 **저장**해야 실제로 적용됩니다.
- 적용 후 **가져오기 되돌리기**로 해당 프로필의 이전 항목·순서·폴더 여는 방식을 복원할 수 있습니다. 다른 등록 항목을 수정하거나 앱을 종료하기 전까지 사용할 수 있으며, 복원한 목록도 탭에서 저장해야 적용됩니다.
- 미리보기 이후 등록 목록이 바뀌면 다시 확인하도록 하며, 프로필이 전환돼도 처음 선택한 프로필에만 적용합니다. 메뉴를 편집하는 동안 새로 수집된 항목과 사용 횟수도 저장 과정에서 보존합니다.
