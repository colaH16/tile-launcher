# Tile Launcher 0.16.3

Option을 누르면 커서 근처에 열리는 macOS용 타일 런처입니다.

- 모든 앱의 최근 창 전환과 앱·폴더 등록
- 앱별 고정 메뉴와 메뉴 막대 자동 수집, 최근·자주 사용 기록
- 집중 모드 필터에 연결하는 프로필과 오버레이 안의 임시 프로필 전환
- 유리·파스텔 / 클래식·직각 테마와 섹션별 색상
- 로그인 시 실행, Dock 항목 가져오기, 고정·이동 가능한 오버레이

업데이트 범위: **첫 공개 → v0.16.3**. 아래 기능은 처음 공개한 앱에 포함된 전체 기능입니다. 개발 중 재분류한 번호는 별도 GitHub 공개 버전이 아닙니다.

## 첫 공개에 포함된 기능

- Option을 0.25초 누르면 커서 근처에 오버레이를 엽니다. 화면 크기/경계를 보정하며 키를 놓으면 닫습니다.
- 앱별 메뉴와 모든 앱의 최근 창을 나란히 표시합니다. 다른 데스크탑의 창도 포함하고 현재 데스크탑 창을 색으로 강조합니다. 앱 전환점은 긴 타일, 같은 앱의 연속 창은 정사각 타일이며 최대 3.3줄과 다음 줄 일부를 보여줍니다.
- 앱·폴더를 등록하고 순서를 바꿉니다. 폴더별로 오버레이 탐색/Finder 열기를 고르고 폴더 안의 파일·앱·하위 폴더를 탐색합니다. 휴지통은 외부 볼륨까지 포함하는 Finder 통합 휴지통을 엽니다.
- Dock에 등록된 앱과 폴더를 원래 순서대로 한 번에 가져옵니다. 기존 등록 항목은 유지합니다.
- 오버레이를 핀 버튼/⌥X로 고정하고 상단 제목·빈 곳을 드래그해 옮깁니다. 고정 중 활성 앱/창을 따라 제목·메뉴·최근 창이 갱신됩니다.
- ⌥W/⌘W/Esc 닫기, ⌥,/⌘, 설정과 macOS 기본 앱 명령을 제공합니다. 숫자 1–9/0으로 첫 열 개를 선택하며 설정에서 등록 항목/최근 창의 기본 조합을 바꿉니다.
- 빈 프로필 추가·현재 구성 복제·프로필/등록 순서 변경을 지원합니다. 오버레이의 가로 스크롤이나 ⌥A/S·⌥D/F로 이번 호출의 프로필을 전환합니다. Focus 필터 연결 기능도 포함하지만 이 개발용 서명 배포본의 알려진 로딩 제한은 아래를 확인하세요.
- 앱별 메뉴를 직접 등록/고정하고 순서를 바꿉니다. 모든 일반 앱의 macOS 메뉴 막대 선택을 자동 수집하며 전체 끄기·앱별 중단·메뉴 제외/복원을 제공합니다. 리본/우클릭/단축키 직접 실행은 수집하지 않습니다.
- 최근 메뉴는 앱별 최근 30일 이내 또는 최근 5개를 유지합니다. 자주 사용은 최근 90일 내 3회 이상이며 두 기간을 설정에서 바꿉니다.
- 메뉴 막대 선택과 Tile Launcher 실행을 함께 집계합니다. 타일에 누적 합계, 설정/툴팁에 경로별 횟수를 표시하고 자주 쓰는 메뉴를 큰 타일로 바꿉니다.
- 유리·파스텔/클래식·직각 테마, 메뉴·최근 창·등록 항목의 색 선택/기본색 복원과 글자 대비 조정을 제공합니다. 앱과 메뉴 막대에 같은 계단/분리 타일 심벌을 사용합니다.
- 로그인 자동 실행과 Option 호출 켜기/끄기를 지원합니다. 같은 빌드는 기존 실행 앱을 유지하고 다른 빌드는 나중에 연 앱으로 교체합니다.

### 0.16.3 — 첫 공개를 마무리한 수정

- 메뉴/최근 창 타일의 마우스 강조를 강화하고 글자 위에 색을 덮지 않습니다.
- Apple 로고의 시스템 메뉴 전체를 자동 수집에서 제외합니다. 직접 고정/수동 등록한 메뉴는 보존합니다.
- 타일의 불투명도는 유지하고 배경 색 레이어를 0.72 → 0.28로 낮췄습니다.
- 오버레이 모서리 밖 유리/배경을 하나의 둥근 윤곽으로 잘라 검은 선을 줄였습니다.
- 설정의 실제 버전/빌드 표시와 개발/배포 빌드의 버전 설정을 맞췄습니다.


## 설치와 시작

Apple Silicon Mac, macOS 26 이상이 필요합니다. Intel Mac은 이번 파일의 지원 대상이 아닙니다.

1. ZIP을 풀고 **Tile Launcher.app**을 응용 프로그램 폴더로 옮깁니다.
2. 앱을 열고 메뉴 막대의 설정에서 접근성 권한을 허용합니다.
3. Option을 길게 눌러 오버레이를 엽니다. ⌥X로 고정하고 Esc/⌥W/⌘W로 닫습니다.
4. 집중 모드는 앱 설정의 자동 프로필 선택을 켠 뒤 시스템 설정의 앱 필터에서 연결합니다.

설치 안내: https://github.com/colaH16/tile-launcher/blob/main/docs/installation.md

## 지원 범위

- **2026-10-13 추가 확인 — Focus 제한:** macOS 27.2 beta에서 현재 ad-hoc 배포본의 Team ID 조회가 실패하며 Focus 필터 로딩이 시간 초과됩니다. 아이콘 파일과 일반 아이콘 로딩은 정상이지만, 유효한 Apple 서명 후 시스템 연결을 재검증해야 합니다. 그동안 앱 안의 수동 프로필 선택·좌우 전환을 사용하세요. 진단: https://github.com/colaH16/tile-launcher/blob/main/docs/focus-diagnostics.md

- 현재 주 검증 환경은 Apple Silicon/macOS 27.2 beta입니다. macOS 26은 최소 실행 대상으로 빌드했으며 별도 실기 검증은 남아 있습니다.
- 메뉴 자동 수집은 실험 기능으로, 앱이 제공하는 접근성 메뉴 정보에 따라 누락될 수 있습니다.
- 다른 데스크탑의 창 구분·전환은 macOS 내부 API를 일부 사용하며 OS 업데이트에 따라 제한될 수 있습니다.
- 집중 모드의 설정 모델/메타데이터는 검증했지만 시스템 필터 전환 전체의 실기 검증은 추가로 필요합니다.
- 입력 문자·클립보드·화면 이미지를 수집하지 않습니다. 설정과 메뉴 사용 기록은 로컬에 저장합니다.

각 파일의 서명·공증 상태는 이 릴리스 설명 앞부분과 release-metadata.json을 확인하세요.
