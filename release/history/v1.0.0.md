## 이전 공개본 이후의 변경

### 1.0.0 — 설정/오버레이 여백 정렬과 정식 서명·공증

- 일반/모양/메뉴/등록 항목·프로필 네 탭의 첫 글자가 같은 높이에서 시작하도록 중복 상단 여백을 정리했습니다. 일반의 권한 박스와 버전 사이/버전 아래 간격도 맞췄습니다.
- 오버레이 바깥 여백, 메뉴/최근 창의 열 사이, 각 섹션 제목과 타일 사이 간격을 같은 기준으로 정리했습니다. 최근 순서·타일 비율·최대 3.3줄과 등록의 완전한 행 표시를 유지합니다.
- 초기 설정 창은 실제 일반 내용에 맞춰 열고 직접 크기를 조절할 수 있습니다. 이 기존 정책을 여백 조정 후에도 유지합니다.
- 첫 Developer ID Application 서명 배포로 전환했습니다. 강화된 런타임·보안 타임스탬프, Apple 공증 Accepted·티켓과 Gatekeeper 검사를 완료했습니다.
- 앱/폴더/프로필/메뉴/사용 기간/색/단축키 설정을 보존합니다. 개발용 ad-hoc 서명에서 전환하며 접근성은 설치한 앱을 기준으로 확인합니다.
- 서명 이후 사용자가 Focus 필터의 프로필 선택 화면이 정상 로딩된다고 확인했습니다. 시스템 설정의 캐시 아이콘과 모든 전환/해제 조합은 별도 확인 대상입니다.

변경 비교: https://github.com/colaH16/tile-launcher/compare/v0.17.6...v1.0.0

## 설치와 사용

Apple Silicon Mac, macOS 26 이상이 필요합니다.

1. ZIP을 풀고 Tile Launcher.app을 응용 프로그램 폴더로 옮깁니다.
2. 앱 설정 → 일반 → 권한에서 접근성을 허용합니다.
3. Option을 길게 눌러 오버레이를 엽니다. ⌥X 고정, ⌥W/⌘W 또는 Esc 닫기, ⌥,/⌘, 설정입니다.
4. 등록 항목·프로필에서 앱/폴더와 수동 프로필을 구성합니다.

설치 안내: https://github.com/colaH16/tile-launcher/blob/main/docs/installation.md

## 지원 및 검증 범위

- 주 검증 환경은 Apple Silicon/macOS 27.2 beta입니다. macOS 26은 최소 빌드 대상으로 선언했으며 별도 실기 검증은 남아 있습니다.
- 메뉴 자동 수집은 앱이 제공하는 접근성 정보에 따라 선택이 누락될 수 있습니다.
- 다른 데스크탑의 창 구분/전환은 macOS 내부 API를 일부 사용하므로 OS 업데이트 후 재확인이 필요합니다.
- 이전 ad-hoc 앱은 Team ID 조회 실패로 Focus 필터가 로딩되지 않았습니다. 서명 후에도 실제 시스템 필터 전환의 성공을 메타데이터/서명 검사만으로 보장하지 않으며 수동 프로필 전환을 계속 제공합니다.
- 입력 문자·클립보드·화면 이미지를 수집하지 않습니다. 설정과 메뉴 사용 기록은 로컬에 저장합니다.
