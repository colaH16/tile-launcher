# Tile Launcher 1.9.3

업데이트 범위: **v1.9.2 → v1.9.3**.

## 이전 공개본 이후의 변경

### 1.9.3 — 고정·자동 수집 메뉴 구분과 정렬 개선

- 설정 → 메뉴의 목록을 **고정**과 **자동 수집**으로 나누고 제목·개수·구분선을 표시합니다. 고정이 없을 때도 핀 사용 안내를 보여줍니다.
- 위·아래 순서 버튼은 고정 메뉴에만 표시합니다. 같은 앱의 고정 메뉴 안에서만 이동하며 첫 항목의 위쪽, 마지막 항목의 아래쪽을 비활성화합니다. 하나뿐이면 양쪽 모두 비활성화합니다.
- 자동 수집의 최근/자주 사용 메뉴는 **메뉴 막대+Tile Launcher 누적 사용 횟수**가 많은 순서로 표시합니다. 동률이면 최근 사용 순서, 횟수와 시각도 같으면 기존 순서를 유지합니다. 설정 목록과 오버레이에 같은 정렬을 적용합니다.
- 자동 수집 항목에 최근/자주 사용 구분을 표시하며, 기존 타일의 크기·색과 기간/최근5개 보존 규칙은 유지합니다. 메뉴 탭의 저장·변경 취소와 사용 기록도 보존합니다.
