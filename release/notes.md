# Tile Launcher 2.1.10

업데이트 범위: **v2.1.9 → v2.1.10**.

### 2.1.10 — 커서 근처 오버레이 위치 수정

- 화면 위·아래 가장자리에서 오버레이가 커서에서 멀리 떨어져 열리던 문제를 수정했습니다. 실제 내용에 맞춘 창 크기를 기준으로 커서 근처에 배치하고, 화면 밖으로 나가는 부분만 보정합니다.
- 새로 여는 경우와 Option을 누르는 동안 미리 준비한 오버레이 모두 같은 위치 규칙을 사용합니다.
- 빠른 재열기와 드래그한 위치 복원, 열린 창의 프로필·내용 변경 위치 규칙은 유지합니다. 타일 크기와 화면 안전 여백도 그대로입니다.

Apple Silicon · macOS 26 이상.
