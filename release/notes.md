# Tile Launcher 0.17.1

Option을 누르면 커서 근처에 열리는 macOS용 타일 런처입니다.

- 모든 앱의 최근 창 전환과 앱·폴더 등록
- 앱별 고정 메뉴와 메뉴 막대 자동 수집, 최근·자주 사용 기록
- 집중 모드 필터에 연결하는 프로필과 오버레이 안의 임시 프로필 전환
- 유리·파스텔 / 클래식·직각 테마와 섹션별 색상
- 로그인 시 실행, Dock 항목 가져오기, 고정·이동 가능한 오버레이

## 이번 수정

- 위치 복원 기본 시간을 **0.8초 → 0.6초**로 줄여, 이동 후 다시 호출했을 때 이전 위치로 열리는 빈도를 줄입니다. 저장된 사용자 설정은 유지합니다.
- 이전 공개본 0.16.3 이후 추가된 보정 기능도 포함합니다. Option을 놓아 선택 없이 닫은 뒤 **기본 0.6초 안에 다시 누르면 직전 오버레이 위치로 즉시 복원**합니다. 재입력 시각으로 판정하며 평소 호출의 0.25초 대기는 유지합니다.
- 설정 → 일반 → Option 재입력 보정에서 켜기/끄기와 0.1–2.0초(0.1초 단위)를 조절합니다. Option 해제 후 창을 닫는 시점은 늦추지 않습니다.
- Esc/닫기/설정·항목 실행·다른 키나 클릭·화면/데스크탑 변경은 복원 대상에서 제외합니다. 창 위치만 잠깐 기억하고 키 입력 내용은 저장하지 않습니다.

기본값 보정 패치 **0.17.1(8)**입니다. 상세 이력은 CHANGELOG.md를 참고하세요. Developer ID 서명을 완료하고 검증한 첫 빌드는 1.0.0으로 전환할 예정입니다. 현재 파일은 개발용 ad-hoc 서명입니다.

## 설치와 시작

Apple Silicon Mac, macOS 26 이상이 필요합니다. Intel Mac은 이번 파일의 지원 대상이 아닙니다.

1. ZIP을 풀고 **Tile Launcher.app**을 응용 프로그램 폴더로 옮깁니다.
2. 앱을 열고 메뉴 막대의 설정에서 접근성 권한을 허용합니다.
3. Option을 길게 눌러 오버레이를 엽니다. ⌥X로 고정하고 Esc/⌥W/⌘W로 닫습니다.
4. 집중 모드는 앱 설정의 자동 프로필 선택을 켠 뒤 시스템 설정의 앱 필터에서 연결합니다.

설치 안내: https://github.com/colaH16/tile-launcher/blob/main/docs/installation.md

## 지원 범위

- **2026-10-13 추가 확인 — Focus 제한:** macOS 27.2 beta에서 현재 ad-hoc 배포본의 Team ID 조회가 실패하며 Focus 필터 로딩이 시간 초과됩니다. 아이콘 파일과 일반 아이콘 로딩은 정상이지만, 유효한 Apple 서명 후 시스템 연결을 재검증해야 합니다. 그동안 앱 안의 수동 프로필 선택·좌우 전환을 사용하세요. 진단: https://github.com/colaH16/tile-launcher/blob/main/docs/focus-diagnostics.md

- 현재 주 검증 환경은 Apple Silicon/macOS 27.2 beta입니다. macOS 26은 최소 실행 대상으로 빌드했으며 별도 실기 검증은 남아 있습니다.
- 메뉴 자동 수집은 실험 기능으로, 앱이 제공하는 접근성 메뉴 정보에 따라 누락될 수 있습니다.
- 다른 데스크탑의 창 구분·전환은 macOS 내부 API를 일부 사용하며 OS 업데이트에 따라 제한될 수 있습니다.
- 집중 모드의 설정 모델/메타데이터는 검증했지만 시스템 필터 전환 전체의 실기 검증은 추가로 필요합니다.
- 입력 문자·클립보드·화면 이미지를 수집하지 않습니다. 설정과 메뉴 사용 기록은 로컬에 저장합니다.

각 파일의 서명·공증 상태는 이 릴리스 설명 앞부분과 release-metadata.json을 확인하세요.
