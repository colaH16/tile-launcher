# Tile Launcher 1.1.5

업데이트 범위: **v1.1.3 → v1.1.5**. 이 구간의 모든 앱 변경을 포함합니다.

## 이전 공개본 이후의 변경

### 1.1.4 — 색상 예시와 등록 타일 구분

- 설정 → 모양의 최근 창 색상 예시에서 오래된 긴 타일을 없앴습니다. 회색 1×1 → 연한색 2×2 → 진한색 2×2의 세 가지로 표시해 진한색을 오른쪽에 둡니다. 컬러 1×1 예시는 넣지 않습니다.
- 진한색은 현재 데스크탑, 연한색은 다른 데스크탑, 회색 작은 타일은 창 없는 앱을 보여줍니다. 선택한 최근 창 색은 두 컬러 예시에 적용하고 회색은 유지합니다.
- 등록 항목에서 앱은 진한색, 폴더는 파스텔로 구분합니다. 등록 색 선택은 양쪽에 적용하고 글자색은 자동으로 맞춥니다. 휴지통은 폴더와 같은 파스텔입니다.
- 등록 색상 예시도 파스텔 폴더 → 진한 앱 정사각형으로 맞췄습니다. 메뉴 예시·실제 오버레이 배치·사용자 설정·실행과 단축키는 유지합니다.

### 1.1.5 — 색상 예시의 열 정렬

- 작은 회색 타일의 자리 폭을 다른 예시와 같은 56pt로 맞췄습니다. 메뉴의 자주 사용·최근 창의 연한색·등록 앱이 같은 왼쪽 시작선에 놓입니다.
- 최근 창 진한색은 고정 메뉴와 같은 열에서 시작하며, 회색 타일 자체는 1×1 크기를 유지합니다. 색·실제 타일 배치·사용자 설정은 유지합니다.

## 설치와 검증 범위

Apple Silicon · macOS 26 이상. 주 검증 환경은 macOS 27.2 beta입니다. 창·다른 데스크탑 판정의 접근성 정보 및 일부 내부 API 제한은 이전 릴리스와 같습니다.

설치 안내: https://github.com/colaH16/tile-launcher/blob/main/docs/installation.md
실제 파일의 서명·공증 상태는 릴리스 상단 안내와 release-metadata.json에서 확인합니다.
