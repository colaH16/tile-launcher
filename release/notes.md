# Tile Launcher 1.9.5

업데이트 범위: **v1.9.4 → v1.9.5**.

### 1.9.5 — 오버레이 드래그와 앱 설정 표시 수정

- 타일·설정/핀 버튼은 누른 곳에서7화면픽셀 움직이면 창을 이동합니다. 처음 잡은 지점을 커서 아래에 유지하고, 드래그 뒤에는 타일을 실행하지 않습니다.
- 빈 배경·타일 사이·섹션 내부 빈자리에서는 별도 거리 문턱 없이 기본 창 이동을 사용합니다. 우클릭 메뉴와 휠/스크롤바 조작을 유지합니다.

- AX 오류·시간 초과·아직 읽을 수 없는 메뉴 구조를 ‘설정 없음’과 구분합니다. 확인 실패는 비활성 타일을 유지하고, 정상 조회에서 설정을 못 찾았을 때만 숨깁니다. 이후 발견하면 활성 타일을 표시합니다.
- 세 경로 중 오류가 남아 있으면 다른 경로의 미발견만으로 설정이 없다고 판단하지 않습니다.
- 총5회 확인 실패 후에는 비활성 ‘앱 설정 · 확인 실패’로 표시하며 추가 조회하지 않습니다.
- 기존 탐색 경로·재시도 횟수·성공 캐시는 유지하며 임시 진단 로그를 추가하지 않았습니다.

Apple Silicon Mac · macOS 26 이상. 이번 전달본은 Developer ID 서명·미공증 시험본입니다.
