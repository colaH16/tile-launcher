# Tile Launcher 2.0.1

업데이트 범위: **v2.0.0 → v2.0.1**.

### 2.0.1 — 같은 이름의 대체 메뉴 실행 수정

- iTerm의 `Profiles › fish`처럼 화면에는 하나로 보이지만 내부에 일반·Option용 메뉴가 함께 있는 경우, 저장된 단축키까지 대조하여 실행할 메뉴를 구분합니다.
- 경로와 단축키가 유일하게 일치할 때만 실행합니다. 구분할 정보가 없거나 정보를 읽지 못하면 다른 메뉴를 임의로 실행하지 않습니다.

사용자 확인을 위한 시험본입니다. Apple Silicon · macOS 26 이상.
