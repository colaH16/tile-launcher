# Tile Launcher 2.1.3

업데이트 범위: **v2.0.0 → v2.1.3**.

### 2.1.3 — 작은 타일·원형 버튼 주변의 사각 흔적 수정

- 큰 타일을 강조할 때 Option 작은 타일 주변에 사각형으로 색 차이가 남던 문제를 수정했습니다. 작은 타일의 실제 크기와 모서리에 맞춰 강조를 나눕니다.
- 빈 배경의 강조가 원형 버튼 주변에서 사각형으로 끊기던 문제를 수정했습니다. 클릭·드래그·메뉴 실행·동기화는 유지합니다.

### 2.1.2 — 기본 타일의 추가 경계선 수정

- 큰 타일에 커서를 올리면 Option 작은 타일 주변에 강조 테두리가 하나 더 생기던 문제를 수정했습니다. 나머지 피드백·클릭·드래그·실행·동기화는 유지합니다.

### 2.1.1 — 선명한 타일과 입력 피드백

- 타일 위에 추가했던 유리 재질을 제거했습니다. 타일은 완전히 불투명하고 글자·아이콘은 선명하게 유지하며, 커서와 클릭에는 반사광·테두리·눌림 강조만 반응합니다.
- 타일 위에서는 해당 영역만, 빈 배경에서는 타일·버튼을 제외한 배경만 반응합니다. 일반 메뉴와 Option 영역도 각각 따로 반응합니다.
- Option 영역은 긴 타일에서도 **오른쪽 위 1×1 정사각형 작은 타일**로 표시합니다. 가장자리와 그림자로 일반 메뉴와 구분합니다. 61의 타일 폭에 따라 길어지는 코너를 수정했습니다.
- 기존 7픽셀 드래그 문턱, 빈 배경의 즉시 이동, 우클릭과 스크롤을 유지합니다.

### 2.1.0 — 한 타일에서 일반·Option 메뉴 실행

- Option 대안이 확인된 메뉴는 한 타일에서 일반 메뉴와 대안 메뉴를 따로 실행할 수 있습니다.
- 앱의 실제 열린 메뉴가 알려 주는 관계를 사용하므로, Finder처럼 Option을 누르면 이름이 달라지는 메뉴도 연결할 수 있습니다. 해당 메뉴를 한 번 열면 확인한 대안을 기존 타일과 메뉴 추가 목록에 반영합니다. 관계를 제공하지 않는 앱이나 닫힌 메뉴만 읽은 경우에는 자동 연결이 제한됩니다.
- 일반·Option의 실행 대상도 함께 동기화합니다. 직접 추가·고정 등 기존 동기화 대상 메뉴에 적용하며, 자동 수집만 한 최근 메뉴/사용 기록은 Mac별로 유지합니다. 수신 Mac에서 앱·전체 경로·식별자를 다시 확인하며, 새 실행 정보 공유에는 양쪽 Mac의 2.1.0 이상이 필요합니다.
- 61의 추가 유리 표면·가변 코너 모양은 위 2.1.1의 피드백과 정사각 코너로 변경했습니다.

### 2.0.1 — 같은 이름의 메뉴 실행 수정

- iTerm 프로필처럼 같은 이름의 일반·Option 메뉴가 함께 있는 경우, 단축키 대신 내부 식별자로 실행 대상을 구분합니다. 단축키 없는 프로필도 선택할 수 있습니다.
- 기존 타일을 다시 선택해도 고정·아이콘·사용 기록을 유지합니다. 구분할 수 없거나 저장 식별자와 다르면 다른 메뉴를 대신 실행하지 않습니다.

사용자 확인용 시험본 · Apple 공증 전입니다.
Apple Silicon · macOS 26 이상. 실제 커서/클릭 피드백과 메뉴 실행은 설치 후 확인해 주세요.
