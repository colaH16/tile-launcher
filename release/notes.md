# Tile Launcher 2.1.0

업데이트 범위: **v2.0.0 → v2.1.0**.

### 2.1.0 — 한 타일에서 일반·Option 메뉴 실행

- Option 대안이 확인된 메뉴 타일은 **우상단 1/4 코너**에서 대안을, 나머지 영역에서 일반 메뉴를 실행합니다. ⌥ 표시와 대안 메뉴 이름으로 구분합니다.
- 앱의 실제 열린 메뉴가 알려 주는 관계를 사용하므로, Finder처럼 Option을 누르면 이름이 달라지는 메뉴도 연결할 수 있습니다. 해당 메뉴를 한 번 열면 확인한 대안을 기존 타일과 메뉴 추가 목록에 반영합니다. 관계를 제공하지 않는 앱이나 닫힌 메뉴만 읽은 경우에는 자동 연결이 제한됩니다.
- 일반·Option의 실행 대상도 함께 동기화합니다. 수신 Mac에서 앱·전체 경로·식별자를 다시 확인하며, 임의로 비슷한 메뉴를 실행하지 않습니다. 새 실행 정보 공유에는 양쪽 Mac의 2.1.0 이상이 필요합니다.

### 2.1.0 — 불투명 타일 위의 Liquid Glass

- 타일의 바탕색은 완전히 불투명하게 유지하고 그 위에 유리 표면과 커서 반사를 표시합니다. **타일 위에서는 그 타일만, 빈 배경에서는 배경만** 반응합니다.
- 타일·설정·핀의 7픽셀 드래그 문턱, 배경의 즉시 이동, 우클릭과 스크롤은 유지합니다. 동작 줄이기·투명도 줄이기 설정도 반영합니다.

### 2.0.1 — 같은 이름의 메뉴 실행 수정

- iTerm 프로필처럼 같은 이름의 일반·Option 메뉴가 함께 있는 경우, 단축키 대신 내부 식별자로 실행 대상을 구분합니다. 단축키 없는 프로필도 선택할 수 있습니다.
- 기존 타일을 다시 선택해도 고정·아이콘·사용 기록을 유지합니다. 구분할 수 없거나 저장 식별자와 다르면 다른 메뉴를 대신 실행하지 않습니다.
