# Tile Launcher 1.1.3

업데이트 범위: **v1.0.0 → v1.1.3**. 이 구간의 모든 앱 변경을 포함합니다.

## 이전 공개본 이후의 변경

### 1.1.0 — 프로필별 크기·창 없는 앱·일반 종료

- 등록 항목을 최근 창 바로 아래에 붙이고 선택한 프로필의 항목 수에 맞춰 오버레이 높이를 줄이거나 늘립니다. 이동한 위치와 윗변을 유지하며 화면 밖으로는 나가지 않습니다.
- 창 없는 일반 앱과 등록된 메뉴 막대 앱은 아이콘과 이름만 있는 작은 1×1 타일로 표시합니다. 이 버전에서는 실제 창을 2×2/4×2로 표시했으며, 최종 1.1.3의 크기와 배치는 아래 1.1.1 항목을 따릅니다. 최근 순서와 숫자 단축키를 유지합니다.
- 작은 앱 타일을 우클릭하면 정상 종료를 요청할 수 있습니다. 앱 관리 권한이나 강제 종료를 사용하지 않으며 앱의 종료 취소를 존중합니다.
- 작은 타일을 읽을 공간을 확보하도록 기본 타일과 정상 최대 패널을 조금 키웠습니다. 큰 화면에서는 최근 창 3.3줄과 등록 최대 3행, 작은 화면에서는 가용 공간에 맞춰 표시하고 스크롤합니다.
- 최근 목록 전체는 유지하면서 화면에 보이는 주변 타일만 렌더링해 큰 목록의 표시 부담을 줄였습니다.
- 투명한 CG 보조 표면을 다른 데스크탑 창으로 표시하지 않습니다. 조회 실패나 시간 초과를 창 없음으로 취급하지 않습니다.

### 1.1.1 — 작은 창 타일 세로 배치

- 최근 창에서 앱이 바뀌는 위치는 2×2, 같은 앱이 연속되면 창 이름이 있는 1×1 타일로 표시합니다. 창 없는 앱은 회색 배경과 앱 이름으로 구별합니다.
- 연속된 작은 타일은 두 개씩 세로로 쌓습니다. 큰 타일 한 줄 높이 안에서 왼쪽에서 오른쪽으로 채운 뒤 다음 줄로 이동하며, 다음 줄이 이전 줄의 빈칸을 메우지 않습니다. 홀수로 끝나는 작은 타일 아래는 비워 둡니다.
- 실제 최근 순서와 숫자 단축키, 현재 데스크탑 강조와 다른 데스크탑 파스텔 색, 창 선택/앱 활성화/정상 종료를 유지합니다. 메뉴 타일은 기존 크기와 배치를 유지합니다.

### 1.1.2 — 메뉴 타일 크기·색 정리

- 고정 메뉴는 강조색 가로형 4×2, 자주 사용은 파스텔 정사각형 2×2, 최근 사용은 회색 정사각형 2×2로 표시합니다. 메뉴와 최근 창이 같은 크기 기준을 사용하며 가로형은 고정 메뉴에만 남습니다.
- 선택한 메뉴 색은 고정·자주 사용에 적용하고 최근 메뉴는 회색을 유지합니다. 두 테마의 모양 설정 예시와 메뉴 안내도 실제 배치에 맞췄습니다.
- 기존 메뉴 데이터·고정/순서·최근/자주 사용 기간·합산 횟수·툴팁·자동 수집·실행 방식은 유지합니다. 최근 창/등록 프로필의 크기와 동작도 유지합니다.

### 1.1.3 — 닫힌 보조 창의 중복 타일 수정

- 앱이 화면에서 닫은 보조 창을 macOS 창 목록에 계속 보관하는 경우, 최근 창에 잘못 표시하지 않도록 표시 순서 상태를 추가로 확인합니다. Apple Developer의 닫힌 General·Account 창과 USBclean의 보조 창에서 확인한 문제를 수정했습니다.
- 실제 창이 남아 있으면 해당 창을 표시하고, 모든 실제 창이 닫힌 앱은 회색 작은 앱 타일 하나로 표시합니다. 실제 다른 데스크탑 창·최소화된 창·숨긴 앱의 창은 유지합니다.
- 조회 실패·시간 초과·내부 함수 미지원은 닫힘으로 단정하지 않습니다. OS 업데이트 후 내부 API의 호환성은 별도 확인 대상입니다.

## 설치와 검증 범위

Apple Silicon · macOS 26 이상. 기존 앱/메뉴/프로필/색/단축키 설정을 유지합니다. 주 검증 환경은 macOS 27.2 beta이며 macOS 26 실기 검증은 별도입니다.

창 없는 판정은 앱이 제공하는 접근성 정보에 따라 제한될 수 있습니다. 다른 데스크탑 정보는 일부 내부 API를 사용하므로 OS 업데이트 후 재확인이 필요합니다. 닫힌 보조 창의 오표시 문제는 1.1.3에서 수정했습니다.

1.0.0 이후 사용자가 Focus 필터의 프로필 선택 화면이 정상 로딩된다고 확인했습니다. 시스템 설정의 캐시 아이콘과 모든 프로필 전환/해제 조합은 별도 확인 대상입니다.

검증: 117개 XCTest와 23개 배포 정책 테스트, 실제 앱의 닫힘·최소화·다른 데스크탑 창 판정, 두 테마의 네이티브 렌더를 확인했습니다. 사용자가 창 없는 앱의 회색 타일과 정상 종료도 확인했습니다.
