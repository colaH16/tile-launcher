# Tile Launcher 2.1.7

업데이트 범위: **v2.1.6 → v2.1.7**.

### 2.1.7 — 첫 실행 후 최근 창 전환 보완

- Safari처럼 첫 실행 직후 창 제어 정보가 아직 제공되지 않은 앱에서, Option을 누른 채 최근 창을 선택하면 전환하지 못하던 경로를 보완합니다. 초기 복구 때 런처에서 대상 앱으로 활성 상태를 명시적으로 넘긴 뒤 원래 선택한 창을 다시 확인합니다.
- Option 키를 가짜로 떼거나 오버레이를 강제로 닫지 않습니다. 이미 창 제어 정보를 확보한 경우의 전환과 앱 연속 실행 동작은 유지합니다.
- 다른 창이 열렸다는 이유만으로 성공 처리하지 않으며, 원래 창의 포커스·데스크탑 상태 확인과 재시도 상한을 유지합니다.

Apple Silicon · macOS 26 이상.
