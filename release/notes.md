# Tile Launcher 2.3.1

업데이트 범위: **v2.3.0 → v2.3.1**.

## 이전 공개본 이후의 변경

### 2.3.1 — Option 유지·고정 상태의 실행과 닫힘 정리

- ⌥+숫자는 Option을 놓을 때가 아니라 누르는 순간 실행합니다. 클릭과 같은 방식입니다.
- Option을 누르고 있는 동안에는 앱·창·메뉴·Handoff·폴더 안 파일을 실행해도 오버레이가 남아 있어 여러 개를 연달아 실행할 수 있습니다. 메뉴 타일도 이제 닫히지 않습니다.
- 고정한 오버레이에서 항목을 실행하면 바로 닫힙니다. 창 없는 앱을 우클릭으로 종료할 때만 계속 열려 있어 연달아 종료할 수 있습니다.
- Finder로 여는 폴더와 휴지통, 권한 설정 열기는 어느 상태에서든 오버레이를 닫습니다.
- 실행한 뒤 Option을 놓아 닫았을 때도 빠르게 다시 누르면 직전 위치에 다시 엽니다.
- 설정과 안내 문구를 바뀐 동작에 맞췄습니다.

Apple Silicon · macOS 26 이상.
