# Tile Launcher 2.0.1

업데이트 범위: **v2.0.0 → v2.0.1**.

### 2.0.1 — 같은 이름의 대체 메뉴 실행 수정

- iTerm의 `Profiles › fish`나 단축키 없는 프로필처럼, 같은 경로에 일반·Option용 메뉴가 함께 있는 경우 내부 식별자를 저장하여 실행 대상을 구분합니다. 단축키는 표시용으로 유지합니다.
- 메뉴 추가 목록에서 iTerm 프로필의 **새 탭·새 창**을 구분해 선택할 수 있습니다. 기존 타일은 **대상 변경**으로 고정·아이콘·사용 기록을 유지하며 갱신합니다. 자동 수집이 켜져 있다면 실제 앱 메뉴를 다시 선택해도 갱신됩니다.
- 식별자 정보는 Mac별로 확인해 보관합니다. 이전 버전이나 iCloud에서 온 타일에 식별자가 없고 경로가 중복되면, 그 Mac에서 원하는 대상을 한 번 선택해 주세요. 구분할 정보가 없거나 읽지 못하면 다른 메뉴를 임의로 실행하지 않습니다.

사용자 확인을 위한 시험본입니다. Apple Silicon · macOS 26 이상.
