# Tile Launcher 2.0.0

업데이트 범위: **v1.9.6 → v2.0.0**.

### 2.0.0 — iCloud 설정 동기화

#### 여러 Mac에서 메뉴와 모양을 함께 사용

- 같은 iCloud 계정의 Mac끼리 직접 추가하거나 편집한 메뉴, 고정 여부·순서, 직접 지정한 아이콘을 동기화합니다.
- 테마와 타일 색상, 앱 설정 타일 표시, Option 재입력 보정과 허용 시간, 숫자 단축키 조합, 최근 창의 자동 배치·수동 최대 개수도 함께 반영합니다.
- 설정 → 일반의 **‘이 Mac에서 iCloud 동기화’**로 Mac마다 참여 여부를 정합니다. 기본값은 꺼짐입니다.
- 등록 앱·폴더·프로필, 자동 수집 설정·사용 기록, 앱에서 읽은 아이콘 캐시, 로그인 항목·권한은 각 Mac에만 유지합니다. 공유되는 항목과 로컬 항목은 설정에서 확인할 수 있습니다.

#### 저장한 변경을 항목별로 병합

- 모양·메뉴 탭은 **저장한 변경만** 동기화합니다. 변경 취소나 아직 저장하지 않은 편집은 다른 Mac에 보내지 않습니다.
- 오프라인이거나 이 Mac의 동기화를 꺼둔 동안 편집해도 실제 수정 시각을 보존합니다. 다시 연결하면 항목별 최신 변경을 합치며, 삭제보다 나중에 편집한 메뉴는 다시 나타납니다.
- 양쪽에서 서로 다르게 바꾼 메뉴 아이콘은 사용자가 선택합니다. 고정 순서는 최신으로 저장한 순서를 따르고 새 메뉴도 보존합니다.
- 처음 연결하는 2.0 이전 설정은 충돌 없는 항목을 합칩니다. 수정 시각이 없는 기존 값끼리 충돌하면 iCloud 값과 이 Mac 값 중 선택합니다.
- 현재 Mac에서 찾을 수 없는 메뉴도 자동으로 지우지 않습니다. 설정 목록에 취소선과 안내를 표시하고, 직접 삭제하기 전까지 데이터를 보존합니다.

#### 빠른 오버레이와 Mac별 제어

- 동기화는 백그라운드에서 진행합니다. 오버레이는 받아둔 로컬 설정으로 바로 열며 네트워크 응답을 기다리지 않습니다. 다른 Mac의 변경이 반영되기까지 약간의 시간이 걸릴 수 있습니다.
- 설정을 열 때 최신 변경을 확인하며, 오프라인이거나 조회가 실패하면 안내 후 로컬 편집을 허용합니다. **‘지금 동기화’**로 다시 확인할 수도 있습니다.
- iCloud 계정이 바뀌면 전송을 보류하고, 다음 오버레이에서 현재 설정을 새 계정과 합칠지 이 Mac의 동기화를 끌지 묻습니다.

Apple Silicon · macOS 26 이상.
