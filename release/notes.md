# Tile Launcher 1.9.4

업데이트 범위: **v1.9.3 → v1.9.4**.

## 이전 공개본 이후의 변경

### 1.9.4 — 오버레이·앱 설정 수정과 아이콘 읽기 개선

- 타일과 버튼을 제외한 오버레이의 빈 배경에서 창을 드래그할 수 있습니다. 스크롤과 타일의 클릭·우클릭 동작은 유지합니다.
- 최근 창의 창 없는 앱 타일에서 종료하면 오버레이를 고정해 유지합니다. 여러 앱을 이어서 종료할 수 있습니다.
- 공통 앱 설정 메뉴는 앱 전환 때 확인하고 결과를 실행 중인 앱별로 기억합니다. 찾은 앱은 다시 조회하지 않고, 찾지 못한 앱도 총 5회까지만 확인합니다. 앱을 재실행하면 다시 확인합니다.
- 오버레이를 열 때 설정 메뉴 조회를 기다리지 않습니다. 설정 메뉴 실행 시에는 실제 항목을 다시 확인합니다.

- 앱 전환·새 앱 실행·등록 항목 변경 때 아이콘을 미리 읽고 기존 캐시를 재사용합니다. 새로 추가되거나 변경된 메뉴의 저장 이미지도 준비합니다. 메뉴 정렬과 이미지 크기·그리기 방식은 유지합니다.
