# Tile Launcher 2.0.0

업데이트 범위: **v1.9.6 → v2.0.0**.

### iCloud 설정 동기화

- 모양과 직접 추가·편집한 메뉴, 고정 순서·아이콘, 앱 설정 타일 표시, Option 재입력 보정, 숫자 단축키, 최근 창 개수를 Mac 간 동기화합니다.
- 일반 탭에서 이 Mac의 참여를 켜고 끕니다. 등록 앱·폴더·프로필 및 자동 수집 설정·사용 기록은 각 Mac에 보존합니다.
- 오프라인 편집은 실제 수정 시각으로 병합하며, 다른 곳에서 삭제한 메뉴도 나중 편집으로 복원할 수 있습니다. 서로 다르게 바꾼 아이콘은 선택합니다.
- 처음 연결하는 2.0 이전 데이터는 충돌 없는 항목을 합치고, 시각이 없는 충돌만 iCloud 값/이 Mac 값을 선택합니다. 계정이 바뀌면 다음 오버레이에서 합치기/끄기를 묻습니다.
- 앱에서 확인되지 않는 메뉴도 자동 삭제하지 않습니다.

개발 중 초안입니다. 실제 iCloud 통신·서명 권한·사용자 확인 및 공증 후 최종 노트를 확정합니다.

Apple Silicon · macOS 26 이상.
