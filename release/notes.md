# Tile Launcher 2.1.11

업데이트 범위: **v2.1.10 → v2.1.11**.

### 2.1.11 — Option 최초 위치와 Help 클릭 수집 개선 시험본

- Option을 처음 감지한 커서 위치를 기준으로 오버레이를 엽니다. 표시 대기 중 마우스를 이동해도 준비·표시·재생성에 같은 좌표를 사용합니다.
- 기존 빠른 재열기의 저장 위치 복원, 수동 호출의 고정 상태와 현재 커서 위치, 화면 안전 경계·타일 크기는 유지합니다.
- 82번은 일반 메뉴 안에 섞인 Group과 그 안의 자식 없는 Button 때문에 전체 메뉴 수집이 중단되던 경로를 개선한 시험본입니다. Group의 실제 메뉴는 빠짐없이 읽고, 자식0을 정상 확인한 Button만 기존 메뉴 후보 범위 밖으로 처리합니다.
- 개선은 옵션 없이 일반 실행해도 적용됩니다. Numbers Help 검색 결과 TSV를 마우스로 선택한 뒤 최근 메뉴에 추가되는지 확인하는 단계이며 실제 성공은 사용자 시험 전입니다.
- 잘못된 위치의 Group, 자식이 있거나 조회가 불확실한 Button, 다른 미지원 역할은 계속 불완전으로 처리합니다. 전체 중복/식별자 검증과 기존 한도·취소·설정 변경 처리는 유지하며 이름/설명/값/액션 추가 조회·재탐색·재시도·캐시는 넣지 않습니다.
- 진단이 필요할 때만 --menu-capture-log와 --menu-capture-structure를 함께 지정하면 기존 제한 구조 진단을 사용할 수 있습니다. 일반 실행에는 추가 구조 진단 조회가 없습니다.
- 이 dev 시험본에는 명시 실행 인자 --menu-capture-log로 켜는 제한된 메뉴 진단이 포함됩니다. 일반 메뉴 클릭·Help 결과 클릭·Help Enter 중 누락되는 단계를 확인합니다.
- Help 검색 결과를 마우스로 선택할 때 행을 먼저 보관하고, 선택이 확정된 뒤 제한된 별도 조회로 실제 메뉴를 연결하도록 수정합니다. 조회 중 입력 처리가 밀리는 문제를 줄이는 dev 시험본이며, 여러 앱의 실제 동작은 사용자 시험으로 확인합니다.
- 불완전하거나 모호한 메뉴는 저장하지 않고, 앱 전환·취소·새 선택·설정 변경 뒤 도착한 오래된 결과는 버립니다. 일반 메뉴 클릭과 Enter 수집은 유지합니다.
- 로그에는 검색어·메뉴 제목·문서/창 내용·키 입력 문자열·원시 좌표를 기록하지 않습니다. 고유한 로컬 파일에 최대 10분·1MiB·200건으로 제한하며 자동 전송하지 않습니다.
- 이 진단 포함 앱은 **Homebrew dev 시험 채널 전용**이며 정식 배포 후보로 자동 승격하지 않습니다.

Apple Silicon · macOS 26 이상.
