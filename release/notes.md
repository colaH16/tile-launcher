# Tile Launcher 2.3.0

업데이트 범위: **v2.1.10 → v2.3.0**.

## 이전 공개본 이후의 변경

### 2.1.11 — 오버레이 위치와 도움말 클릭 수집 개선

- Option 키를 누르고 표시를 기다리는 동안 커서를 움직여도, 처음 누른 커서 위치를 기준으로 오버레이가 열리도록 수정했습니다.
- 일부 앱에서 도움말 메뉴 검색 결과를 마우스로 선택했을 때 최근 사용 메뉴에 추가되지 않던 문제를 수정했습니다.

### 2.2.0 — 메뉴 경로 표시

- 메뉴 타일에서 상위 경로를 작은 글씨로 메뉴 이름 위에 표시해, 명령이 속한 메뉴를 쉽게 확인할 수 있습니다.
- 저장된 경로가 있는 메뉴에 표시하며, 긴 경로는 가운데를 줄여 보여 줍니다. 전체 경로는 기존 툴팁에서 확인할 수 있습니다.

### 2.3.0 — 기본 프로필과 설정 편집 개선

- 설정에서 기본 프로필을 따로 지정합니다. 집중 모드 자동 선택 중 연결된 필터가 없으면 지정한 기본값을 사용하고, 수동 선택은 별도로 유지합니다.
- 설정에서 편집할 프로필을 바꿔도 런처의 현재 수동 선택이나 자동 선택 설정은 바뀌지 않습니다. 등록 항목과 Dock 가져오기·되돌리기도 선택한 편집 대상을 따릅니다.
- 빈 프로필 추가·프로필 복제 버튼을 누르면 이름 입력 창이 열립니다. 복제는 버튼을 누른 시점의 구성을 사용하며 취소하면 바뀌지 않습니다.
- 기본값 프로필은 새 집중 모드 필터 후보에서 제외합니다. macOS에 이미 연결된 필터는 남을 수 있으며 앱에서 적용을 제한합니다. 기존 연결 변경은 시스템 설정에서 진행합니다.
- 등록 탭의 자동 선택 토글이 저장 전에 실제 설정을 바꾸던 연결을 수정했습니다. 기본값·자동 선택·등록 편집은 해당 탭의 저장/변경 취소를 따릅니다.

## 준비 상태

코드와 격리 검증을 마친 뒤 버전 메타데이터를 2.3.0(85)로 정리한 단계입니다. 아직85번 앱을 빌드·서명·공증·배포하지 않았습니다. 회사 Mac의 기존 오마 자동 선택 현상은 원인이 확정되지 않았으며 이번 구조 개선으로 해결됐다고 단정하지 않습니다. 이전84번의 메뉴로 켜는 프로필 진단 시험 안내는 과거 기록으로 보존하고 이번 기능 구역과 구분합니다.

Apple Silicon · macOS 26 이상.
