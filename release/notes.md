# Tile Launcher 1.4.2

업데이트 범위: **v1.1.5 → v1.4.2**. 중간 로컬 버전 1.2.0·1.2.1·1.3.0·1.4.0·1.4.1을 포함합니다. 1.2.0의 앱 묶음 정렬은 아래 1.3.0의 개별 창 정렬로 대체됐습니다. 이번 전달은 공증 없이 다른 Mac에서 시험할 ZIP이며 새 GitHub 공개 릴리스가 아닙니다.

## 이전 공개본 이후의 변경

### 1.4.2 — 타일만 크게, 상단은 기본 크기로

- 메뉴와 최근 창 중 더 긴 쪽이 두 줄이면2줄, 세 줄이면3줄로 맞춥니다. 네 줄 이상일 때만3.3줄로 다음 줄을 살짝 보여줍니다. 짧은 목록은 오버레이 높이도 함께 줄어듭니다.

- 핀/닫기·설정·뒤로 버튼을 기본 Glass 스타일32pt로 바꾸고, 가운데 앱 이름과 창 이름도 일반적인 제목 크기로 줄였습니다. 상단 여백을 줄여 헤더가92pt에서52pt가 됐습니다.
- 섹션 제목·프로필·하단 안내와 창 모서리도 확대하지 않습니다. 타일과 내부 글자/아이콘의1.3배 크기는 유지합니다.
- 확보한 높이를 목록에 쓰고 프로필에 맞춰 전체 높이를 조절합니다. 작은 화면에서 등록39개를 세 줄로 표시하는 검사를 유지하며 최근 창은 남은 높이에 따라 표시합니다.

### 1.4.1 — 1.3배 오버레이와 여백·등록 목록 개선

- 기본 확대를1.3배로 줄이고, 바깥 여백과 영역 사이 간격은 확대 전 기준으로 유지합니다. 상단 버튼 위아래 공간도 줄였습니다.
- 등록 앱39개인데 한 줄만 보이고 아래에 빈 공간이 남는 높이 계산을 수정했습니다. 작은 화면에서는 최근 창 영역을 조금 줄여 등록 목록도 여러 줄 보이도록 맞춥니다. 사용할 수 있는 목록 높이를 정수 행 수로 버리지 않습니다.
- 타일 내부 비율·색/크기의 의미·개별 창 순서·실행 피드백·설정은 유지합니다. 서명된 미공증 시험 ZIP이며 개발 Mac 설치본과 기존 공개 릴리스는 보존합니다.

### 1.4.0 — 앱 실행 대기, 설정 정리와 데스크탑 전환 보완

- 앱을 여는 동안 해당 앱 타일에 대기 표시를 띄우고 중복 실행을 막습니다.3초 내 시작을 확인하지 못하면 해제하고, 시작했다면 macOS의 실행 완료 신호까지 기다립니다. 오류·종료 시 바로 해제하며 완료 신호가 없는 앱은60초 뒤 해제합니다. 다른 앱과 창은 계속 사용할 수 있습니다.
- 최근 창 위에는 색 범례 대신 세 타일 모양과 ‘현재 모니터 / 다른 모니터 / 안 보임’을 표시합니다. 설정의 설명은 다섯 줄로 줄여 항상 보이고, 기본 창 높이는 일반 내용 전체가 한 화면에 들어가도록 맞춥니다. 네 탭의 여백·정렬과 메뉴 목록/하단 추가 버튼도 함께 확인합니다.
- 숫자 단축키를 누르면 타일에 눌림 표시와 선택한 이름이 나타납니다. 고정 모드에서는 실행 요청 뒤에도 짧게 타일을 강조하고, 일반 모드에서는 기존처럼 Option을 놓으면 실행과 함께 닫힙니다.
- 다른 데스크탑의 창을 기존 화면 위에 겹쳐 보이게 할 수 있는 직접 Space 변경 호출을 제거하고 macOS의 앱·창 활성화 경로를 사용합니다. 대상 창의 포커스를 확인하며 확인할 수 없으면 오류를 알려줍니다. 실제 보고 환경에서의 재현/해결 확인은 아직 별도이며 OS 설정과 앱의 접근성 지원에 따라 전환이 제한될 수 있습니다.

### 1.3.0 — 개별 창 최근 순서와 위치별 타일

- 같은 앱의 모든 창을 함께 이동하지 않고, 각 창을 최근 활성화한 순서대로 표시합니다. 목록에서 앱이 처음 나오면 진한색, 이미 나온 앱의 다른 창은 파스텔입니다. 창 없는 앱은 회색 1×1입니다.
- 활성 앱의 가장 최근 보이는 창이 있는 모니터에서 보이는 데스크탑은 4×2, 다른 모니터의 보이는 데스크탑은 2×2, 보이지 않는 데스크탑은 1×1입니다. 같은 앱의 반복 창도 위치에 따라 크기를 정합니다.
- 두 모니터에 걸친 창은 겹치는 면적이 큰 모니터를 사용합니다. 모니터 정보가 부족한 보이는 창은 2×2, 데스크탑 정보도 미확인이면 1×1로 보수적으로 표시하며 툴팁에 구분합니다.
- 1.2.1에서 보고된 글자 번짐을 개선하기 위해 전체 화면에 걸던 확대 변환을 제거하고 글꼴·아이콘·간격을 실제 크기로 그립니다. 최대 1.4배 크기와 화면 경계 제한은 유지합니다.
- 일반 설정의 설명, 모양의 반복/첫 등장 예시, 최근 창의 색 범례를 함께 갱신했습니다. 표시 중 번호 고정·프로필·메뉴·창 없는 앱 종료는 유지합니다.

### 1.2.1 — 큰 아이콘과 1.4배 오버레이

- 1.2.0의 앱 묶음 배치를 유지하면서 오버레이의 타일·아이콘·글자·등록 항목을 최대 1.4배로 표시합니다. 화면 작업 영역에 맞춰 배율과 높이를 제한하며 프로필 전환 시 윗변과 위치를 유지합니다.
- 앱 아이콘 비율을 키우고 메뉴·창·등록 항목의 제목을 왼쪽 아래에 한 줄로 배치합니다. 긴 제목은 줄여 표시하며 전체 이름은 툴팁과 접근성 이름으로 확인할 수 있습니다.
- 확대 배율에 맞춰 창 모서리와 헤더 드래그·버튼 제외 영역을 함께 조정했습니다. 유리 테마의 작은 타일은 둥근 모서리가 하단 제목을 자르지 않도록 맞췄습니다.

### 1.2.0 — 앱별 창 묶기와 활성 앱 대표 창

- 같은 앱의 창을 한 묶음으로 모으고 현재 활성 앱 묶음을 맨 앞에 표시합니다. 나머지 앱 묶음은 가장 최근 창의 사용 순서를 따르며 묶음 안의 기존 창 사용 순서도 유지합니다. 각 타일은 계속 개별 창을 선택합니다.
- 활성 앱의 현재 보이는 대표 창 하나만 4×2 가로형으로 표시합니다. 모든 모니터의 현재 보이는 데스크탑에 있는 나머지 창은 2×2, 다른 데스크탑이나 위치가 확인되지 않은 창은 제목이 있는 1×1입니다. 활성 앱에 보이는 실제 창이 없으면 가로형 타일은 만들지 않습니다.
- 색은 타일 크기와 독립적으로 모든 모니터의 보이는 데스크탑 기준을 유지합니다. 보이는 창은 진한색, 다른 데스크탑 창은 파스텔이며 창 없는 앱은 회색 1×1입니다.
- 표시와 숫자 단축키는 같은 묶음 순서의 창 목록을 사용합니다. Option을 누르는 동안 순서·번호·타일 크기를 유지하고, 고정 상태에서 활성 앱이 바뀌면 해당 묶음과 대표 창을 갱신합니다.
- 자동 모드의 전체 목록·3.3줄 표시와 스크롤, 작은 타일의 세로 쌍 배치, 프로필별 창 높이·메뉴·등록 항목·색 설정은 유지합니다. 수동 제한은 앱별 묶음을 정한 뒤 적용합니다.

## 설치와 검증 범위

Apple Silicon · macOS 26 이상. 주 검증 환경은 macOS 27.2 beta입니다. 접근성 정보가 불완전한 앱의 창 확인·제어 및 일부 내부 데스크탑 API의 OS 호환성 제한은 유지됩니다. Aside의 일시적 누락 보고는 재현되지 않았으며 이번 기능 변경의 해결 항목으로 표시하지 않습니다.

설치 안내: https://github.com/colaH16/tile-launcher/blob/main/docs/installation.md
실제 파일의 서명·공증 상태는 릴리스 상단 안내와 release-metadata.json에서 확인합니다.
