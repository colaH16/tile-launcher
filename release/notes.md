# Tile Launcher 2.1.8

업데이트 범위: **v2.1.7 → v2.1.8**.

### 2.1.8 — 호출 방식 구분과 앱 실행 탐색 개선

#### 오버레이 닫힘 동작

- 메뉴 막대에서 연 오버레이에서 Option을 누른 채 최근 창을 선택했을 때, 고정하지 않은 오버레이가 남던 경계 동작을 수정합니다.
- Option으로 연 오버레이는 창 선택·데스크탑 전환 중 계속 유지되고, 고정하지 않았다면 Option을 놓을 때 닫힙니다.

#### 앱 실행 탐색 비용 절감

- 앱 식별자가 다른 프로세스를 먼저 제외해, 실행 대상을 찾는 동안 불필요한 파일 경로 조회를 줄입니다. 본체와 보조 프로세스의 구분 및 앱 식별자가 없는 경우의 기존 판별은 유지합니다.
- 수동/Option 호출·고정 상태와 실행 프로세스 판별의 회귀 검사를 보강합니다.

#### 앱 시작 직후 최근 창 갱신

- 앱 실행 완료보다 실제 창 정보가 늦게 준비되는 경우, 대상 앱의 초기 창 목록을 제한된 횟수로 다시 확인합니다. 시작 중 실패한 창 알림 등록도 복구해 오버레이를 다시 열어야 창이 나타나는 경로를 보완합니다.

Apple Silicon · macOS 26 이상.
