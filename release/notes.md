# Tile Launcher 2.1.9

업데이트 범위: **v2.1.8 → v2.1.9**.

### 2.1.9 — 메뉴 막대 좌·우클릭 분리

- 메뉴 막대 좌클릭, 메뉴의 열기, Finder/Dock 앱 재실행 등 Option 호출 이외의 모든 수동 호출은 기존 오버레이가 처음부터 고정 상태로 열립니다. 왼쪽 위 닫기 버튼으로 한 번에 닫을 수 있습니다. 이미 열려 있으면 같은 창을 고정하고 앞으로 가져옵니다.
- 우클릭하면 기존 메뉴(열기, 설정, 접근성 권한 요청, 종료)를 표시합니다. 메뉴를 닫은 뒤 좌클릭해도 고정 오버레이가 열립니다.
- 기존 Option 길게 누르기와 빠른 재열기는 고정하지 않으며, 고정 버튼을 따로 누르지 않았다면 Option을 놓으면 닫힙니다.

로컬 시험본이며 사용자 실기 확인 전 새 공증·정식 공개·Homebrew 갱신은 진행하지 않습니다.

Apple Silicon · macOS 26 이상.
