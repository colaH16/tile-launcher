# Tile Launcher 1.9.6

업데이트 범위: **v1.9.5 → v1.9.6**.

### 1.9.6 — 앱 설정 탐색 취소 범위 수정

- 앱 설정을 확인하던 앱이 종료되거나 대상이 바뀌어 탐색을 중단할 때, 다른 앱의 설정 탐색까지 함께 취소될 수 있는 처리를 수정했습니다.
- 중단된 탐색 다음에 대기 중인 앱을 이어서 확인하도록 보완했습니다.
- 접근성 권한이 사라지거나 앱 설정 타일 표시를 끄면 전체 탐색을 중단하는 동작은 유지합니다.

Apple Silicon · macOS 26 이상. 사용자 확인용 시험본이며 공증·정식 공개 전입니다.
