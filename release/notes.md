# Tile Launcher 1.9.4

업데이트 범위: **v1.9.3 → v1.9.4**.

## 이전 공개본 이후의 변경

### 1.9.4 — 오버레이 조작과 앱 설정 탐지 개선

- **빈 배경에서 창 이동:** 타일·버튼을 제외한 오버레이 배경 전체를 드래그할 수 있습니다.
- **여러 앱 연속 종료:** 최근 창의 창 없는 앱 타일에서 앱을 종료해도 오버레이가 유지됩니다.
- **앱 설정 탐지 개선:** Messages 등 앱 실행 직후 설정 타일이 나타나지 않던 문제를 개선했습니다. 앱 실행 때 미리 탐색하고 세 경로를 동시에 확인해 먼저 찾은 결과를 사용합니다. 준비가 늦으면 최초 포함 총5회까지 자동 재시도합니다.
- **탐색 상태 표시:** 처음에는 비활성 ‘앱 설정 · 확인 중’ 타일을 표시합니다. 첫 실패 때 숨기고, 이후 찾으면 활성 타일을 다시 표시합니다.
- **지원 결과 기억:** 한 번 찾은 앱은 대상 앱을 재실행해도 타일런처가 실행 중인 동안 결과를 기억합니다. 실제 메뉴 실행 전에는 현재 항목을 다시 확인합니다.
- **아이콘 미리 읽기:** 앱 실행·전환이나 등록 항목·메뉴 변경 때 기존 아이콘을 미리 준비해 표시 시 로딩을 줄였습니다.
- **배포 앱 정리:** 임시 비교·probe·상세 로그를 제거하고 개발용 검증·미리보기 코드를 배포 앱에서 제외했습니다.

## 사용 환경

- Apple Silicon Mac · macOS 26 이상
- 창 조회·전환과 Option 입력 감지에는 접근성 권한이 필요합니다.
- 사용 중인 앱을 종료한 뒤 새 앱으로 교체해 주세요. 기존 설정은 유지됩니다.
