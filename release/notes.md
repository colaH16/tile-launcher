# Tile Launcher 2.1.7

업데이트 범위: **v2.1.6 → v2.1.7**.

### 최근 창 전환과 오버레이 유지

- Safari·Safari Technology Preview를 처음 실행한 뒤, Option을 누른 채 최근 창을 선택하면 전환되지 않던 문제를 보완했습니다. 런처의 실제 활성 상태를 확인한 뒤 대상 앱으로 넘기고 선택한 창을 다시 확인합니다.
- Option을 누르는 동안은 최근 창을 선택하거나 해당 창의 데스크탑으로 전환해도 오버레이가 유지됩니다. 고정하지 않았다면 Option을 놓을 때 닫힙니다.

### 앱 실행 표시 수정

- 일부 앱의 보조 프로세스를 앱 본체로 잘못 인식해, 실행이 끝나도 등록 타일의 로딩과 클릭 차단이 남던 문제를 수정했습니다. 앱 식별자와 본체 실행 파일을 함께 확인하고, 실제 실행 결과로 추적 대상을 정정합니다.
- 정확한 창 전환이 확인된 경우에도 해당 프로세스의 실행 대기를 해제합니다. 다른 창으로 전환된 것을 성공으로 처리하지 않으며 기존 확인·재시도 상한을 유지합니다.

Apple Silicon · macOS 26 이상.
