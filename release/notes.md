# Tile Launcher 2.1.6

업데이트 범위: **v2.1.5 → v2.1.6**.

### 2.1.6 — 앱 실행 후에도 오버레이 유지

- 앱 타일을 클릭해도 오버레이가 닫히지 않아 여러 앱을 이어서 실행할 수 있습니다. 등록 앱, 폴더 안의 앱, 최근 앱과 창 없이 실행 중인 앱 선택에 적용합니다.
- 앱 실행의 대기 표시와 ‘실행 준비 중 / 실행 완료’ 안내는 유지합니다. Option을 누른 채 앱을 실행하는 동작도 그대로입니다.
- 자동으로 고정하지는 않습니다. 일반 호출은 Option을 놓으면 닫히고, 고정한 오버레이는 계속 유지됩니다. 실제 창 전환과 메뉴·폴더 실행의 기존 동작은 유지합니다.

Apple Silicon · macOS 26 이상.
