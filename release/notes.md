# Tile Launcher 1.1.4

업데이트 범위: **v1.1.3 → v1.1.4**. 이 구간의 모든 앱 변경을 포함합니다.

## 이전 공개본 이후의 변경

### 1.1.4 — 최근 창 색상 예시 수정

- 설정 → 모양의 최근 창 색상 예시에서 오래된 긴 타일을 없앴습니다. 진한색 2×2·연한색 2×2·회색 1×1의 세 가지로 표시합니다. 컬러 1×1 예시는 넣지 않습니다.
- 진한색은 현재 데스크탑, 연한색은 다른 데스크탑, 회색 작은 타일은 창 없는 앱을 보여줍니다. 선택한 최근 창 색은 두 컬러 예시에 적용하고 회색은 유지합니다.
- 메뉴·등록 항목 예시, 실제 오버레이 배치·색·사용자 설정은 유지합니다.

## 설치와 검증 범위

Apple Silicon · macOS 26 이상. 주 검증 환경은 macOS 27.2 beta입니다. 창·다른 데스크탑 판정의 접근성 정보 및 일부 내부 API 제한은 이전 릴리스와 같습니다.

설치 안내: https://github.com/colaH16/tile-launcher/blob/main/docs/installation.md
실제 파일의 서명·공증 상태는 릴리스 상단 안내와 release-metadata.json에서 확인합니다.
