# Tile Launcher 1.9.5

업데이트 범위: **v1.9.4 → v1.9.5**.

### 1.9.5 — macOS 창 이동 문제 우회 대응과 앱 설정 표시 개선

#### 1. 창 드래그 개선

- **macOS 27.2 beta 4 환경의 창 이동 문제에 대응하는 우회 처리를 적용했습니다.** 일부 창에서 드래그가 시작되지 않는 상황에서도 타일을 끌어 오버레이를 이동할 수 있도록 별도 이동 경로를 마련했습니다.
- 타일·설정·핀 버튼은 누른 곳에서 7픽셀 움직이면 창을 이동합니다. 처음 잡은 지점을 커서 아래에 유지하고, 드래그 뒤에는 타일을 실행하지 않습니다.
- 빈 배경·타일 사이·섹션 내부 빈자리에서는 별도 거리 문턱 없이 직접 창을 이동합니다. 우클릭 메뉴와 휠/스크롤바 조작을 유지합니다.
- 원형 설정·핀 버튼을 눌렀을 때 사각형 강조가 겹치던 표시를 수정했습니다.

#### 2. 앱 설정 타일 표시 개선

- **메뉴 섹션의 ‘앱 설정’ 타일:** 현재 활성화된 앱의 ‘설정’ 메뉴를 확인하는 데 실패한 경우와, 해당 앱에 ‘설정’ 메뉴가 없는 경우를 구분합니다. 확인하지 못한 경우에는 타일을 비활성 상태로 유지하고, 설정 메뉴가 없다고 확인된 경우에만 숨깁니다. 이후 설정 메뉴를 찾으면 타일을 활성화합니다.
- 총 5회 확인에 실패하면 ‘앱 설정 · 확인 실패’로 표시하고 추가 조회를 중단합니다.

Apple Silicon Mac · macOS 26 이상. Developer ID 서명 및 Apple 공증 완료.
