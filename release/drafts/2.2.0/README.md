# 2.2.0 공개 초안

메뉴 경로 표시 기능은 설계 중이며 아직 구현하지 않았습니다. 이 폴더는 다음 공개를 위한 초안입니다. 글꼴·배치 등 확정 전인 디자인은 약속하지 않습니다.

다음 GitHub 공개는 **v2.2.0 하나**로 묶습니다. v2.1.10 이후의 두 버그 수정은 2.1.11 구역에, 메뉴 경로 표시 기능은 2.2.0 구역에 유지합니다. 별도의 v2.1.11 GitHub 릴리스나 태그는 만들지 않습니다.

현재 활성 배포 설정은 **2.1.11(82)** 입니다. 이 초안은 활성 `release/config.json`, `release/notes.md`, `release/notes-range.json`을 바꾸지 않습니다.

메뉴 경로 UI 구현과 검증을 마친 뒤, 실제 결과에 맞춰 초안의 예정 표현을 다듬고 활성 설정의 버전을 2.2.0으로 변경할 때 적용합니다. 그때 CHANGELOG.md의 2.2.0 설계 구역을 실제 구현 결과로 갱신하고, 이 폴더의 notes.md와 notes-range.json을 활성 파일로 옮겨 범위를 다시 검증합니다. 현재 초안 검사는 실제 CHANGELOG.md의 2.1.11/2.2.0 구역으로 범위를 검증합니다.

이 초안은 빌드·서명·공증·게시 완료를 뜻하지 않습니다.
