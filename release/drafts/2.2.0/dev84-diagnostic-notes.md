# Tile Launcher 2.2.0

업데이트 범위: **v2.1.10 → v2.2.0**.

## 84번 프로필 진단 시험본 안내

이 @dev 시험본은 집중 모드에 맞는 런처 프로필이 표시되지 않는 현상을 확인하기 위한 프로필 진단을 포함합니다. 정식 배포용 앱이 아니며 원인 수정 완료를 뜻하지 않습니다. 기본 실행에서는 기록하지 않고 메뉴의 ‘프로필 진단 시작’으로 직접 켭니다. 집중 모드를 바꾸고 평소처럼 런처를 연 뒤 진단을 중지하고 로그 폴더를 열 수 있습니다. 별도 실행 인자는 필요하지 않습니다. 아래 두 버전 구역은 기존 변경 내역이며 이번 진단을 새 정식 기능으로 추가하지 않습니다.

## 이전 공개본 이후의 변경

### 2.1.11 — 오버레이 위치와 도움말 클릭 수집 개선

- Option 키를 누르고 표시를 기다리는 동안 커서를 움직여도, 처음 누른 커서 위치를 기준으로 오버레이가 열리도록 수정했습니다.
- 일부 앱에서 도움말 메뉴 검색 결과를 마우스로 선택했을 때 최근 사용 메뉴에 추가되지 않던 문제를 수정했습니다.

### 2.2.0 — 메뉴 경로 표시

- 메뉴 타일에서 상위 경로를 작은 글씨로 메뉴 이름 위에 표시해, 명령이 속한 메뉴를 쉽게 확인할 수 있습니다.
- 저장된 경로가 있는 메뉴에 표시하며, 긴 경로는 가운데를 줄여 보여 줍니다. 전체 경로는 기존 툴팁에서 확인할 수 있습니다.

Apple Silicon · macOS 26 이상.
