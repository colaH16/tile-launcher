# 2.3.0 공개 계획

R392 사용자는 설정/프로필 UI 변경을 포함하므로 마이너 버전을 올리자고 요청했다. 다음 공개 계획은 v2.3.0으로 변경하며 이전 v2.2.0 단일 공개 계획을 대체한다. v2.1.10 이후 변경은2.1.11 두 수정·2.2.0 메뉴 경로·2.3.0 기본 프로필/설정 UI의 세 구역으로 보존한다. v2.1.11의 별도 GitHub 공개·태그는 만들지 않는다.

버전/config는2.3.0(85)이며 실제85 앱 빌드·서명·공증·설치·@dev/GitHub 배포는 이번 요청에서 진행하지 않았다. 회사 오마 자동 선택 원인은 미확정이다. 기존2.2.0 draft는 역사로 보존하며 dev84 진단 안내는 그 폴더의 dev84-diagnostic-notes.md에 보관한다. 이 폴더의 노트는 현재 활성 노트와 같고 실제 공개 전에 검증/실기 결과에 맞춰 상태 문구를 갱신한다.
