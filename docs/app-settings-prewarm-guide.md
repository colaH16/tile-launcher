# 앱 실행 사전 탐색 시험 · 1.9.4(52)

> 과거 시험 빌드용 안내입니다. 1.9.4(53) 배포 후보에서는 compare/probe/임시 로그 옵션을 제거했습니다. 아래 명령을 53 이상에 적용하지 마세요.

이 시험본은 일반 Tile Launcher다. build51의 비교 전용 실행과 달리 메뉴 막대 아이콘과 Option 오버레이가 나온다. 기존 설치 앱을 덮어쓰지 않고 압축을 푼 폴더에서 실행한다. Developer ID 서명·미공증 시험본이며 정식 공개·설치 교체는 하지 않았다.

## 실행과 검증

1. 기존 Tile Launcher와 Messages를 ⌘Q로 완전히 종료한다.
2. 압축을 풀고 `일반 실행 + Messages 로그.command`를 실행한다. 터미널에 로그 경로가 나오고 메뉴 막대 아이콘이 생긴다. 이번에는 compare/probe 옵션을 쓰지 않는다.
3. 그다음 Messages를 직접 실행한다. Option을 먼저 누르거나 다른 앱으로 전환할 필요가 없다. 앱 실행 완료 알림으로 설정 탐색을 시작한다.
4. Option으로 확인한다. 아직 첫 탐색 중이면 회색 비활성 ‘앱 설정 · 확인 중’ 타일이다. 세 경로가 모두 못 찾거나 오류로 끝난 첫 회차 뒤에는 타일을 숨긴다. 숨긴 뒤에도 재시도하고, 나중에 찾으면 활성 타일을 표시한다. 고정 오버레이에서도 같은 상태를 갱신한다.
5. 재시도는 완료 후0.4·0.8·1.6·3.2초 간격이며, 최초 포함 총5회다. 세 경로 묶음이 한 회차다. 미발견·AX 오류·전체 조회 마감은 재시도하고 취소·종료·프로세스 변경은 성공으로 게시하지 않는다. 정해진 회수를 모두 썼는데 못 찾으면 타일을 숨긴 채 중단한다. ‘확인 실패’가 앱에 설정이 없다는 증명은 아니다.
6. 한번 성공한 앱의 지원 캐시는 대상 앱을 종료·재실행해도 Tile Launcher가 실행 중인 동안 유지한다. 대상 앱이 종료되면 해당 프로세스의 실패 횟수는 초기화한다.
7. 검증 후 메뉴 막대 아이콘에서 Tile Launcher를 종료하고 `~/Library/Logs/TileLauncher/`의 이번 JSONL을 전달한다. 일반 실행이므로51과 달리60/90초 자동 종료가 없다. 터미널에서 중단하려면 Control+C를 사용할 수도 있지만, 완전한 shutdown 로그를 남기려면 메뉴의 종료를 사용한다.

기존에 실행 중이던 미확인 앱은 활성화 때도 탐색한다. 이미 탐색 중이면 중복 작업을 만들지 않는다. 실행 알림으로 시작한 사전 탐색은 다른 앱으로 전환해도 계속한다. 백그라운드 앱은 한 번에 하나씩 준비하고, 활성화된 앱이 대기열에 있으면 먼저 탐색한다. 각 앱은3경로로 탐색하고, 전체 AX 작업자 풀은 최대12개로 두어 활성 앱이 다른 앱의 응답을 기다리지 않게 한다.

실제 경로는 multiple/children/roleFirst다. 먼저 전체 설정 후보를 확인한 경로의 결과를 사용하고 나머지 경로는 다음 AX 호출 전에 중단한다. 이미 macOS에 보낸 동기 AX 호출은 강제 중단할 수 없다. 오버레이 열기는 캐시만 읽고 설정 메뉴를 다시 탐색하지 않는다. 설정 타일을 사용자가 누르면 실행할 메뉴를 다시 확인하는 기존 과정은 유지한다.

로그는 이번 명령의 Messages 탐지만 상세 기록한다. 다른 앱도 화면에서 동작을 확인할 수 있지만 해당 앱의 상세 AX 로그까지 남기는 실행은 아니다. 비교 전용 build51 로그와 일반 제품 build52 로그를 혼동하지 않는다.
