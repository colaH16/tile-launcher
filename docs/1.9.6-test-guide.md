# Tile Launcher 1.9.6(57) 시험 안내

Developer ID 서명·미공증 시험본입니다. 정식 공개본과 설치본은 1.9.5(56)으로 유지했습니다. 시험 ZIP을 풀어 앱을 실행하면 기존 실행본을 교체해 실행하며, 설정·등록 목록은 그대로 사용합니다.

## 바뀐 점

앱 하나의 설정 확인을 중단해야 할 때 다른 앱의 확인 작업과 대기 목록을 보존합니다. 중단된 앱 다음의 대기 앱도 이어서 확인합니다. 화면 배치·창 이동·7픽셀 문턱·설정 탐지 경로와 5회 제한은 그대로입니다.

## 확인해 주세요

1. 기존 Tile Launcher를 종료하고 시험 앱을 실행합니다. 설정 화면 하단에서 **1.9.6 · 빌드 57**인지 확인합니다.
2. Messages와 Discord처럼 설정 메뉴가 있는 앱 두 개를 종료했다가 연달아 실행합니다. 각 앱을 활성화하고 런처를 열었을 때 **앱 설정** 타일이 확인 후 활성화되는지 봐주세요. Discord는 준비가 늦을 수 있습니다. 활성화된 타일을 누르면 해당 앱의 설정이 열려야 합니다.
3. 가능하면 한 앱이 아직 확인 중일 때 그 앱만 종료해 보세요. 남은 앱으로 전환하면 설정 타일이 계속 확인되고 활성화되어야 합니다. 타이밍을 맞추기 어렵다면 억지로 반복할 필요는 없습니다. 정확한 중단 경합은 격리 검사로 확인했습니다.

권한을 일부러 해제하는 검사는 필요 없습니다. 이번에는 창 드래그를 바꾸지 않아 드래그 전체 재시험도 요구하지 않습니다.

문제가 있으면 앱 이름, 실행/종료 순서, 타일이 ‘확인 중’인지 ‘확인 실패’인지 알려주세요. 상세 진단 로그는 이번 배포 앱에 추가하지 않았습니다.

## 자동 확인 범위

기존 코드의 문제 재현 실패와 수정 후 통과, 다른 앱 진행/대기 작업 보존, 자식 작업 중단 뒤 대기 앱 진행, 권한 상실 전체 중단을 검사했습니다. 자동 검사는 사용자 앱 실행이나 실제 접근성 통신을 흉내 낸 격리 검사이므로 실환경 재현률이나 체감 지연을 측정한 것은 아닙니다.

사용자 확인 뒤 공증·정식 배포를 진행합니다.
