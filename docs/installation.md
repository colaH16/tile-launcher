# Tile Launcher 설치

Apple Silicon Mac용 ZIP입니다. macOS 26 이상을 실행 대상으로 빌드하며 실제 확인한 OS 범위와 제한은 릴리스 노트를 확인하세요.

1. 이 저장소의 Releases에서 ZIP, release-metadata.json, SHA256SUMS.txt를 받습니다.
2. 다운로드 폴더에서 `shasum -a 256 -c SHA256SUMS.txt`로 ZIP과 함께 받은 release-metadata.json의 체크섬을 확인할 수 있습니다. SHA256SUMS.txt에 나열된 파일을 모두 같은 폴더에 둡니다. 체크섬은 파일 무결성 확인이며 Apple 공증을 대신하지 않습니다.
3. ZIP을 풀고 Tile Launcher.app을 `/Applications`(응용 프로그램)로 옮깁니다. 기존 버전이 있으면 앱을 종료하고 교체합니다.
4. 앱을 열고 메뉴 막대에서 설정으로 들어갑니다. 접근성 권한 안내에 따라 시스템 설정에서 Tile Launcher를 허용합니다.
5. Option을 누르면 오버레이가 열립니다. 등록 항목과 메뉴를 설정에서 추가할 수 있습니다.

## 개발용 서명·공증 없음으로 표시된 릴리스

0.16.3 파일은 개발용 ad-hoc 서명이며 Apple의 Developer ID 서명/공증을 받지 않았습니다. 처음 실행할 때 macOS가 개발자 또는 안전성을 확인할 수 없다는 이유로 차단할 수 있습니다.

본인이 신뢰하는 이 저장소에서 받은 파일이며 변조되지 않았음을 확인했다면, 앱 실행을 한 번 시도한 후 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**로 해당 앱의 실행을 허용할 수 있습니다. 이후 표시되는 확인 창에서 열기를 선택합니다. 관리되는 Mac은 조직 정책상 이 방법이 허용되지 않을 수 있습니다.

이는 첫 실행에 대한 예외 허용입니다. 접근성 권한은 별도로 필요합니다. 앱이 손상되었거나 악성 콘텐츠가 감지되었다는 다른 경고를 같은 문제로 간주하지 마세요. 전역 Gatekeeper 비활성화나 터미널로 격리 속성을 제거하는 방법은 설치 절차에 포함하지 않습니다.

[Apple의 앱 실행 경고와 허용 안내](https://support.apple.com/ko-kr/102445)

## 업데이트와 집중 모드

- **0.16.3 알려진 제한:** macOS 27.2 beta에서 ad-hoc 앱의 Team ID 조회 실패와 Focus 필터 로딩 시간 초과를 확인했다. 폴더 이동/반복 권한 재등록으로 해결됐다고 확인되지 않았다. 유효한 Apple 서명 후 Focus를 재검증해야 하며, 그동안 앱 안에서 프로필을 수동 선택/전환한다. 자세한 근거는 [진단 기록](focus-diagnostics.md)을 참고한다.

- 앱 ID와 사용자 설정 저장 형식을 유지합니다. 개발용 서명이 달라지거나 설치 경로를 바꾸면 접근성 권한을 다시 허용해야 할 수 있습니다.
- 집중 모드 사용 시 앱 설정의 ‘집중 모드 필터에 따라 프로필 자동 선택’을 켜고, 시스템 설정의 해당 집중 모드 → 앱 필터에서 Tile Launcher와 프로필을 연결합니다.
- 개발/테스트 사본을 같은 앱 ID로 여러 경로에서 실행하면 시스템 등록이 혼동될 수 있습니다. 실제 사용하는 사본을 기준으로 설정하세요.
- 휴지통은 Finder의 통합 휴지통으로 열립니다. 일반 폴더와 달리 오버레이에서 직접 탐색하거나 비우지 않습니다.
