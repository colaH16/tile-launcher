# R180 · 타일 크기와 여백의 높이 비교

2026-10-15. 사용자가 R179 렌더의 여백을 확정했고 타일만1.4배로 키울지 비교 중이다. 제품 앱/ZIP은1.4.2(26)이며 이번 작업은 렌더 시안이다.

## 공통 조건

- 작업 영역2560×1056pt: 사용자의2560×1080 화면에서 메뉴 막대 등을 제외한 비교 가정이며 실측은 아니다.
- 같은 합성 목록: 창19개, 메뉴9개, 등록39개.39개 중18개는 기존 realistic fixture, 나머지는 고유 경로의 합성 앱이다.
- 같은 다크 클래식 색과 창 순서/크기 규칙.①은 앱 버전1.0.0이 아니라 확대 전1.0배의 크기/여백 재구성이다.
- 사진을 전체 너비에 맞춰 축소하지 않는다. 각 창의 왼쪽/중앙/오른쪽220pt 세로 구간을 원본 축척으로 자르고 네 윗변을 맞춘다.
