## 읽는 법

**출처는 전부 `unknown`이다.** 아래 `출처 증거`는 판단 재료일 뿐이고, 출처를 확정하는 사람은 사용자다.

| 출처 값 | 의미 |
|---|---|
| `user` | 사용자가 명시적으로 정함 |
| `agent-proposed→accepted` | 에이전트가 제안했고 사용자가 승인함 |
| `agent-default` | 에이전트가 알아서 고름. 기억나지 않는 것도 여기로 |
| `unknown` | 아직 미정 (지금 전부) |

`출처 증거`에 붙은 표시:

| 표시 | 뜻 | 증거 무게 |
|---|---|---|
| **[원문]** | 사용자가 직접 친 문장 (Codex/Claude 세션 기록) | 높음 |
| **[선택]** | 에이전트가 물었고 사용자가 골랐거나 답한 기록. 질문 문구는 에이전트가 쓴 것 | 높음 (제안→수락 후보) |
| **[2차]** | `docs/request-log.md`, `requirements.md` 등 에이전트가 쓴 요약에만 있음 | 낮음 |
| (비어 있음) | 사용자 쪽 흔적을 못 찾음 | `agent-default` 후보 |
