## 1. 목적

Mac에서 터치바·Stream Deck이 하던 일, 즉 손 가까운 곳에서 앱·창·메뉴를 바로 실행하는 일을 **Option 키 하나로 뜨는 큰 타일 오버레이**로 한다. Dock을 없애는 것이 목표다. [u/h D-004-1, D-032-1]

- 등록 앱: 위치가 고정되고 숫자 키로 실행하는, 손이 외우는 경로 [u/h D-041-1]
- 최근 창: 순서가 바뀌어도 되는 마우스용 목록 [u/h D-041-1]
- 메뉴: 단축키 없이 메뉴로만 쓰던 명령을 타일로 [u/h D-047-1]

### 하지 않는 것

- App Store 배포, App Sandbox [u/h D-005]
- 창 썸네일 [u/h D-022-1]
- 타일에 유리 재질 [u/h D-061-1]
- 색 의미 범례 [u/s D-042-2]
- 메뉴 이미지 파일 업로드 [u/h D-051-2]
- 입력 문자·Help 검색어 저장 [d/s D-022-2]
- 리본·우클릭 메뉴 수집 [u/h D-047-1]

## 2. 호출과 닫기

### 요구

- 좌/우 Option을 단독으로 누르고 있으면 오버레이가 뜬다. 그 전에 다른 키를 누르면 취소한다. 설정에서 끌 수 있다. [u/h D-032-1, a/s D-032-2]
- Option을 누른 순간의 커서 위치를 중심으로, 그 커서가 있는 화면 안에 연다. [u/h D-033-1, D-033-2, D-033-3]
- 메뉴 막대 아이콘: 좌클릭은 고정 오버레이, 우클릭은 메뉴. [u/h D-035-1]
- Option이 아닌 방법(메뉴의 열기, 앱 재실행 등)으로 열면 고정 상태로 연다. [u/h D-035-2]
- 핀 버튼·⌥X로 고정한다. 고정하면 핀 자리가 ×로 바뀐다. 다시 호출하면 고정은 풀린다. [u/h D-034-1, u/s D-034-2]
- 클릭은 누르는 즉시 실행한다. 마우스를 올리는 것만으로는 실행하지 않는다. [u/s D-036-1]
- ⌥+숫자도 누르는 즉시 실행한다. Option을 뗄 때까지 기다리지 않는다. [u/h D-036-2]
- 닫히는 규칙: [u/h D-034-1, D-034-3, D-062]

  | | Option 유지 | 고정 |
  |---|---|---|
  | Option을 떼면 | 닫힘 | 유지 |
  | 앱·창·메뉴(앱 설정 포함)·Handoff·폴더 탐색 속 파일을 실행하면 (클릭·⌥+숫자 모두) | 유지 | 닫힘 |
  | Finder로 폴더·휴지통 열기 | 닫힘 | 닫힘 |
  | 창 없는 앱 우클릭 종료 | 유지 | 유지 (예외) |
  | 설정·권한 화면으로 이동 | 닫힘 | 닫힘 |
  | ×·Esc·⌘W·⌥W | 닫힘 | 닫힘 |

  Option 유지에서 Handoff·폴더 탐색 속 파일은 유지, Finder 폴더·휴지통은 닫힘 [u/h D-066-1 (2026-11-16 사용자 선택)]

- Option을 누른 채 다른 데스크탑의 창을 고르면 배경은 그 데스크탑으로 넘어가고 오버레이는 남는다. [u/h D-066-2]
- 앱을 실행하면 실행 대기·눌림 피드백을 보여준다. [u/h D-066-1]
- Option을 떼서 닫힌 직후 기본 0.6초 안에 Option만 다시 누르면 직전 위치에 다시 연다. 그 사이 항목을 실행했어도 같다. 0.1~2.0초, 켜기/끄기는 설정에서. [u/h D-037-1, u/s D-037-2]
- 오버레이 안 단축키: ⌥X 고정, ⌥W 닫기, ⌥, 설정, ⌘W, ⌘,, Esc. 오버레이가 입력을 받을 때만 처리하고 다른 앱의 단축키는 가로채지 않는다. [u/s D-034-2]

### 완료 조건

```gherkin
Scenario: Option 홀드로 열고 떼면 닫힌다
  Given 오버레이가 닫혀 있고 Option 호출이 켜져 있다
  When  Option만 250ms 이상 누른다
  Then  커서 위치를 중심으로 오버레이가 열린다
  When  아무것도 고르지 않고 Option을 뗀다
  Then  오버레이가 닫힌다

Scenario: 대기 중 커서가 움직여도 처음 누른 자리에 연다
  Given 커서가 화면 A 지점에 있다
  When  Option을 누르고 250ms 안에 커서를 B 지점으로 옮긴다
  Then  오버레이의 중심은 A 지점이다 (화면 가장자리면 화면 안쪽으로 보정)

Scenario: ⌥+숫자는 누르는 즉시 실행한다
  Given Option을 누른 채 오버레이가 열려 있고, 등록 항목 2번이 앱이다
  When  Option을 누른 채 2를 누른다
  Then  2번 앱이 그 순간 실행된다
  And   오버레이는 열려 있다
  When  Option을 뗀다
  Then  오버레이가 닫히고, 2번 앱은 다시 실행되지 않는다

Scenario: 고정 상태에서 실행하면 닫힌다
  Given 오버레이가 고정돼 있다
  When  최근 창 타일 하나를 클릭한다
  Then  그 창으로 전환되고 오버레이가 닫힌다

Scenario: 고정 상태에서 ⌥+숫자도 즉시 실행하고 닫힌다
  Given 오버레이가 고정돼 있고, 등록 항목 2번이 앱이다
  When  ⌥2를 누른다
  Then  2번 앱이 그 순간 실행되고 오버레이가 닫힌다

Scenario: Option을 누르고 있어도 Finder 폴더·휴지통 열기는 닫힌다
  Given Option을 누른 채 오버레이가 열려 있고, 등록 항목에 Finder로 여는 폴더가 있다
  When  그 폴더 타일을 클릭한다
  Then  Finder에서 폴더가 열리고 오버레이가 닫힌다

Scenario: 고정 상태에서도 창 없는 앱 종료는 오버레이를 닫지 않는다
  Given 오버레이가 고정돼 있고, 창 없는 앱 타일이 두 개 있다
  When  첫 번째 앱 타일을 우클릭해 종료한다
  Then  오버레이는 열려 있어 두 번째 앱도 바로 종료할 수 있다

Scenario: Option을 누르는 동안 메뉴를 실행해도 닫히지 않는다
  Given Option을 누른 채 오버레이가 열려 있다
  When  메뉴 타일을 클릭한다
  Then  메뉴가 실행되고 오버레이는 열려 있다
  When  Option을 뗀다
  Then  오버레이가 닫힌다

Scenario: 메뉴 막대 좌클릭은 고정 오버레이를 연다
  Given 오버레이가 닫혀 있다
  When  메뉴 막대 아이콘을 좌클릭한다
  Then  오버레이가 고정 상태(× 버튼)로 열린다
  When  메뉴 막대 아이콘을 우클릭한다
  Then  앱 메뉴가 열린다

Scenario: 실수로 Option을 뗐다가 바로 다시 누르면 같은 자리에 연다
  Given 오버레이를 드래그로 옮긴 뒤 고르지 않고 Option을 떼서 닫았다
  When  0.6초 안에 Option만 다시 누른다
  Then  오버레이가 닫히기 직전 위치에 바로 열린다

Scenario: 실행한 뒤 Option을 떼서 닫혀도 같은 자리에 다시 연다
  Given Option을 누른 채 ⌥2로 앱을 실행했고, 오버레이는 열려 있다
  When  Option을 떼서 닫은 뒤 0.6초 안에 Option만 다시 누른다
  Then  오버레이가 닫히기 직전 위치에 바로 열린다
```

## 3. 화면 구성과 외관

### 요구

- 배치: 위 왼쪽 메뉴, 위 오른쪽 최근 창, 아래 전체 폭 등록 항목. [a/h D-039]
- 닫기·핀은 왼쪽 위, 앱 이름·창 설명은 가운데, 설정은 오른쪽. [u/h D-040-2]
- 최근 창은 최대 3.3줄을 보여 다음 줄이 살짝 보이게 하고 나머지는 세로 스크롤. 등록 항목은 그 바로 아래에 붙고, 프로필을 바꾸면 행 수에 맞춰 높이가 바뀐다. [u/h D-045-1]
- 화면이 허용하면 타일만 1.2.0 크기의 최대 1.4배로 키운다. 헤더·버튼은 Safari 수준 크기를 유지한다. [u/h D-045-2]
- 테마: 유리·파스텔(기본) / 클래식·직각. 섹션마다 기준 색을 고른다. [a/s D-060-1, u/s D-060-2]
- 배경과 버튼만 Liquid Glass, 타일은 불투명. 커서가 있는 타일과 빈 배경에 반응 피드백. [u/h D-061-1, u/s D-061-2]
- 빈 배경 어디서나 끌어 옮길 수 있다. 타일 위에서는 7물리픽셀 넘게 움직여야 드래그, 그보다 짧으면 클릭. [u/h D-065-1, D-065-2, u/s D-065-3]
- Option 대기 중 오버레이를 미리 만들어 둔다. [u/h D-063]
- Option 유지·고정 모두 활성 앱·창·메뉴·Handoff 변화를 실시간 반영한다. ⌥+숫자 실행 표시·마우스 눌림 중에는 잠깐 미룬다. [u/h D-062]

### 완료 조건

```gherkin
Scenario: 타일 위 짧은 움직임은 클릭, 긴 움직임은 드래그
  Given 오버레이가 고정돼 있다
  When  타일을 누른 채 5물리픽셀 움직였다가 놓는다
  Then  그 타일이 실행되고 오버레이는 움직이지 않는다
  When  타일을 누른 채 20물리픽셀 움직였다가 놓는다
  Then  오버레이가 움직이고 타일은 실행되지 않는다

Scenario: 프로필을 바꾸면 높이가 바뀐다
  Given 등록 항목 1줄짜리 프로필로 오버레이가 열려 있다
  When  등록 항목 3줄짜리 프로필로 넘긴다
  Then  오버레이 윗변은 그대로이고 높이만 늘어난다
```

## 4. 최근 창

### 요구

- 모든 앱의 열린 창을 앱 구분 없이 개별 창 단위로, 최근 사용 순으로 보인다. [u/h D-041-2]
- 다른 데스크탑의 창도 넣고, 현재 데스크탑 창은 강조한다. [u/h D-043-1]
- 타일 크기는 데스크탑 위치(활성 모니터에서 보임 4×2 / 다른 모니터에서 보임 2×2 / 안 보임 1×1), 색은 앱 첫 등장(강조) / 반복(파스텔) / 창 없는 앱(회색). [a/h D-042-1]
- 창 없는 실행 앱은 1×1 회색 타일. 우클릭하면 정상 종료를 요청한다(강제 종료 없음). [u/s D-043-2]
- Dock에 Handoff 항목이 있으면 최근 창 첫 칸을 Handoff 타일로 덮는다. [u/h D-044-1]
- 숫자 단축키: 기본 ⌥1–0 등록 항목, ⌥⌘1–0 최근 창. 설정에서 맞바꾼다. [u/s D-038]

### 완료 조건

```gherkin
Scenario: 다른 데스크탑의 창도 보인다
  Given 데스크탑 1에 Safari 창, 데스크탑 2에 Terminal 창이 열려 있고 지금 데스크탑 1이다
  When  오버레이를 연다
  Then  Safari와 Terminal 창 타일이 모두 보이고 Safari 타일만 현재 데스크탑 강조색이다
```

## 5. 메뉴

### 요구

- 모든 앱의 macOS 메뉴 막대에서, 메뉴 클릭·열린 메뉴의 Enter·Help 검색 결과 클릭으로 실행한 명령을 자동으로 모은다. 전체 끄기·앱별 중단·메뉴별 제외를 제공한다. [u/h D-047-1, d/s D-047-2]
- 복사·붙여넣기도 메뉴로 골랐다면 모은다. Apple(로고) 메뉴와 그 하위는 뺀다. [u/h D-048-1, D-048-2]
- 최근: 30일 이내 또는 최근 5개. 자주: 90일 안 3회 이상. 기간은 설정에서. 런처 실행과 메뉴 막대 선택을 둘 다 센다. [u/h D-049-1, D-049-2, d/s D-049-3]
- 한 섹션에서 크기·색으로 구분: 고정 4×2 강조 / 자주 2×2 파스텔 / 최근 2×2 회색. [u/h D-046-1, a/s D-046-2]
- 고정은 사용자가 정한 순서, 자동 수집은 누적 사용 횟수순. 오버레이에는 구분선이 없고, 설정 창 메뉴 탭에는 제목과 구분선이 있다. [u/s D-046-3, u/h D-046-4]
- 타일 표시: 아이콘 → 단축키 → 메뉴 이름 큰 글자. 아이콘은 직접 고른 SF Symbol, 앱 리소스에서 가져온 아이콘(PDF 보존), 몇몇 메뉴의 기본 아이콘 순. [u/h D-051-1, D-051-2, a/s D-051-3, u/s D-051-4]
- 일반 크기 타일에는 부모 메뉴 경로를 이름 위에 작게 보인다. [u/h D-052-1, u/s D-052-2]
- Option 대체 메뉴가 있으면 타일 우상단 정사각 코너(짧은 변의 절반)가 대체 메뉴를 실행한다. [u/h D-053-1, D-053-2]
- 메뉴는 선택 당시의 앱에서만 실행한다. 앱이 바뀌었으면 실행하지 않는다. 실패해도 자동으로 다시 실행하지 않는다. [d/h D-050-1]
- 언어가 바뀌어도 같은 메뉴로 알아본다. 후보가 여럿이면 실행하지 않는다. [a/h D-031-1, d/h D-016-1]
- 현재 앱에 표준 설정 메뉴(⌘, 등)가 있으면 메뉴 끝에 "앱 설정" 타일을 붙인다. 탐지 오류면 비활성, 오류 없이 못 찾으면 숨긴다. 설정 → 메뉴 맨 위에서 끌 수 있다. [u/h D-054-1, D-054-2, u/s D-054-3]

### 완료 조건

```gherkin
Scenario: 메뉴로 실행한 명령이 수집된다
  Given 자동 수집이 켜져 있고 Numbers가 앞에 있다
  When  메뉴 막대에서 파일 › 내보내기 › PDF…를 클릭한다
  Then  Numbers의 메뉴 영역에 "PDF…" 타일이 추가되고 경로 "파일 › 내보내기"가 이름 위에 보인다

Scenario: Help 검색 결과 클릭도 수집된다
  Given 자동 수집이 켜져 있다
  When  Help 검색 결과에서 메뉴 항목을 마우스로 클릭한다
  Then  그 메뉴가 수집된다

Scenario: 한 달에 한 번 쓰는 메뉴가 사라지지 않는다
  Given Excel 메뉴 6개를 썼고, 그중 "이미지 크기 줄이기"는 40일 전에 마지막으로 썼으며 나머지 5개는 그보다 최근이다
  When  오버레이를 연다
  Then  "이미지 크기 줄이기"는 최근 목록에서 숨겨진다 (30일이 지났고 최근 5개 밖)
  And   설정 → 메뉴에는 기록이 남아 있다

Scenario: 다른 앱으로 잘못 실행하지 않는다
  Given 오버레이를 고정한 뒤 앞의 앱이 Safari에서 Finder로 바뀌었다
  When  고정 전 Safari 문맥으로 표시된 메뉴 타일을 누른다
  Then  Safari가 아니면 실행하지 않는다
```

## 6. 등록 항목·프로필·집중 모드

### 요구

- 등록 항목: 앱, 폴더(오버레이 탐색 또는 Finder 열기), 다운로드, Finder 통합 휴지통(Finder로만). [u/h D-055-1, D-055-2]
- Dock 가져오기: Dock의 앱·폴더를 순서대로 한 번에. 미리보기 후 적용, 되돌리기 가능. [u/h D-056-1, D-056-2]
- 프로필마다 등록 목록. 빈 프로필 추가 / 현재 구성 복제, 만들 때 이름 입력. 기본·마지막 프로필은 삭제 불가. [u/s D-057-1, D-057-2, d/s D-057-3]
- 가로 쓸기·⌥A/S·⌥D/F로 프로필을 넘긴다. 넘긴 것은 이번 오버레이에서만. [u/s D-058-1, a/s D-058-2]
- 집중 모드 필터로 프로필이 바뀐다. 기본 프로필을 지정할 수 있고, 필터가 없으면 기본 프로필로 돌아간다. 기본 프로필은 필터 후보에서 뺀다. [u/h D-059-1, D-059-3, a/s D-059-4]

### 완료 조건

```gherkin
Scenario: 집중 모드 필터가 없으면 기본 프로필
  Given 프로필 "기본"이 기본값이고, "Work" 집중 모드에만 "Work" 프로필 필터가 연결돼 있다
  When  Work 집중 모드를 켜고 오버레이를 연다
  Then  등록 항목은 "Work" 프로필이다
  When  집중 모드를 끄고 오버레이를 연다
  Then  등록 항목은 "기본" 프로필이다

Scenario: 넘긴 프로필은 다음 호출에 유지되지 않는다
  Given 오버레이에서 ⌥D로 다음 프로필로 넘겼다
  When  오버레이를 닫고 다시 연다
  Then  원래 프로필(집중 모드 또는 기본)로 열린다
```

## 7. 동기화

### 요구

- 여러 Mac 사이에서 메뉴와 일부 설정을 동기화한다. 등록 앱·프로필·사용 기록·자동 수집 on/off는 각 Mac에 둔다. [u/h D-010-1, D-011]
- Mac마다 켜고 끄며 기본은 꺼짐. 오버레이는 네트워크를 기다리지 않는다. [a/s D-010-3, D-010-4]
- 충돌은 실제 편집 시각이 늦은 쪽이 이긴다. 삭제보다 늦은 편집이 있으면 메뉴를 되살린다. [u/h D-012-1, a/h D-012-2]

### 완료 조건

```gherkin
Scenario: 오프라인 편집도 실제 시각으로 합친다
  Given 두 Mac 모두 동기화가 켜져 있고, Mac B가 오프라인이다
  When  Mac A에서 10:00에 메뉴 X를 삭제하고, Mac B에서 10:05에 메뉴 X의 아이콘을 바꾼 뒤 Mac B가 온라인이 된다
  Then  두 Mac 모두에서 메뉴 X가 남아 있고 바뀐 아이콘을 쓴다
```

## 8. 설정 창과 앱 수명

### 요구

- 설정 탭: 일반 / 모양 / 메뉴 / 등록 항목·프로필. 권한은 일반 하단. [requirements R76, R116 — decisions에 별도 항목 없음]
- 일반 탭은 바로 저장, 나머지 탭은 탭별 저장/취소. [u/s D-064]
- 로그인 시 자동 실행(사용자 선택). [u/h D-013-1]
- 한 번에 하나만 실행. 같은 빌드면 새로 뜬 쪽이 종료, 다르면 최근 실행본을 남긴다. [u/s D-014-1]
- 접근성 권한만 필수. 화면 녹화·전체 디스크 접근은 요구하지 않는다. [a/s D-006]

### 완료 조건

```gherkin
Scenario: 저장/취소 탭은 저장 전까지 반영되지 않는다
  Given 설정 → 모양에서 메뉴 색을 바꿨다
  When  저장하지 않고 오버레이를 연다
  Then  오버레이의 메뉴 색은 바뀌기 전 색이다
  When  설정 → 모양에서 저장을 누르고 오버레이를 연다
  Then  바뀐 색이 보인다
```
