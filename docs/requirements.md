# 현재 요구사항

최종 기록일: 2026-10-12 (Asia/Seoul)

현재 작업 범위: **R52에서 선택한 첫 레이아웃을 네이티브 0.2에 적용하고 남은 메뉴·프로필 기능을 구현**. 제품명 Tile Launcher. R30에 따라 `colaH16/tile-launcher` 커밋·푸시는 승인됨. 기존 MIT 라이선스와 이력을 유지하며 Sites·App Store·Homebrew 게시/배포는 진행하지 않음.

이 문서는 현재 기준이다. 변경 전 요구와 시안 피드백은 [요청 기록](request-log.md)에 보존하며, 코드 구현과 실제 검증 결과는 [검증 기록](validation.md)에서 구별한다.

## 제품과 플랫폼 경험

- Option으로 큰 오버레이를 불러 앱·창·메뉴를 빠르게 선택한다. 터치바와 Stream Deck의 접근성을 키보드 가까이 가져오는 것이 목적이다.
- 타일은 공간 배치와 넓은 클릭 영역을 위한 UX다. Windows 외관을 복제하지 않는다. SwiftUI/AppKit과 지원 SDK의 Liquid Glass를 사용한다.
- 닫기/핀과 뒤로 가기는 왼쪽, 앱 이름·최근 창 설명은 중앙, 프로필/설정은 오른쪽의 네이티브 유리 그룹이다. 제목 중앙은 좌우 버튼 너비와 독립적이다.
- macOS 기본 메뉴·⌘W 닫기·⌘, 설정·⌘H 가리기·⌘Q 종료와 포커스·접근성 관례를 유지한다. 다른 앱의 단축키를 전역에서 소비하지 않는다.
- Apple 지침과 재질은 OS 업그레이드 때 [업그레이드 절차](macos-upgrade-guide.md)로 재확인한다. 시안 CSS나 임의 곡률을 Apple의 고정 규격으로 취급하지 않는다.
- 기능을 우선한다. 향후 Homebrew Cask를 고려하며 App Store는 필요한 기능을 유지할 수 있을 때만 검토한다.

## R52 확정 레이아웃

- 첫 비교안 채택: **위 왼쪽 메뉴 / 위 오른쪽 최근 창 / 아래 전체 폭 등록 항목**. 메뉴와 최근 창의 시작·끝 높이와 타일 모듈을 맞춘다.
- 최근 창은 전역 최근 순서다. **첫 창 또는 바로 앞 창과 앱이 다르면 가로형, 같으면 정사각형**. 가로형은 정사각형 둘과 간격을 합한 너비이며 높이는 같다.
- `Terminal cc2 → Terminal se3 → Safari → Terminal local`은 가로형·정사각형·가로형·가로형이다. 앱마다 창이 하나라면 모두 가로형이다. 떨어져 있는 같은 앱의 창을 모으거나 중복 제거하지 않는다.
- 큰 타일도 그 개별 창을 전환한다. 별도 최근 앱 영역은 표시하지 않는다. **R52는 초기 앱/창 분리 요구 및 R47–R51의 미정 상태를 대체한다.**
- 행 우선으로 순서대로 배치한다. 가로형이 다음 줄로 넘어가 생긴 빈칸에 뒤 항목을 끌어올리지 않는다. 두 줄을 넘어서는 항목은 해당 영역에서 세로 스크롤한다.
- 타일 크기/최근 순서가 사용에 따라 변하는 사용자 취향을 유지하되, 선택 중 대상이 움직이지 않도록 표시 시점의 순서·크기를 고정하고 다음 호출에 갱신한다. 이는 에이전트가 정한 초기 조작 정책이다.
- 메뉴는 고정·빈도·최근을 한 섹션에서 크기와 배경/핀으로 구분한다. 고정 메뉴는 가로형으로 맨 앞, 빈도 메뉴는 가로형, 나머지는 정사각형이다. 큰 메뉴 둘을 한 행에 나란히 놓는다.
- 등록 앱·폴더만 작게 표시한다. R60에서 아이콘 32pt를 유지하며 최소 60pt 정사각 타일과 8pt 간격으로 보완했다. 은은한 배경/연속 곡선 테두리·마우스 반응·우상단 숫자를 사용하며 메뉴/최근 창 크기는 유지한다.

## 호출·고정·숫자 단축키

- 초기 기본값: 좌/우 Option 단독 250ms. 표시 전 타이핑·다른 보조키 조합은 호출을 취소한다. 표시 이후 Command 추가만으로 닫지 않는다.
- 클릭 또는 숫자로 명시적으로 선택하고 Option을 놓으면 실행한다. 포인터를 올리는 것만으로 실행하지 않는다. 고정하지 않은 패널에서 선택 없이 놓으면 닫는다.
- R53 **사용자가 확정한 기본값은 ⌥1–9/0 등록 항목, ⌥⌘1–9/0 최근 창**. 설정의 라디오 선택으로 두 대상을 서로 바꾼다. 0은 10번째이며 첫 10개에 숫자 배지를 표시한다. 각 제목 줄에 현재 조합을 안내한다.
- 숫자는 오버레이가 키 입력을 받을 때만 로컬 처리한다. 열기 전 조합이나 다른 앱에 포커스가 있을 때는 가로채지 않는다. 한국어/영어 입력과 무관한 물리 숫자열 및 숫자 키패드를 지원하며 Shift/Control을 추가한 조합은 숫자 선택으로 해석하지 않는다.
- 숫자를 고른 뒤 다른 숫자로 대상을 바꿀 수 있고 반복 키는 재실행하지 않는다. 취소·설정·핀 조작은 이전 실행 대기를 취소한다. 없는 번호는 실행하지 않는다.
- 폴더의 ‘오버레이 탐색’은 기존 클릭과 같이 바로 진입한다. 안에서는 숨겨진 등록/최근 창 번호를 실행하지 않는다. 파일·앱/Finder 열기는 Option 해제까지 기다린다.
- 왼쪽 위 핀 또는 ⌥X로 현재 패널을 고정하고 같은 자리는 닫기 ×로 바뀐다. 고정 상태는 Option 해제·바깥 클릭에 유지되며 Esc/⌘W/×로 닫는다. 재호출 시 고정은 초기화한다.
- R59: 핀 버튼/⌥X는 같은 처리기로 앱 활성화와 패널의 키보드 포커스를 요청한다. Command 조합은 패널의 key-equivalent 경로와 로컬 키 이벤트를 공통 처리한다. 다른 앱을 명시적으로 선택한 후에는 그 앱의 단축키를 가로채지 않는다.
- 고정 중 항목 실행은 패널을 유지하되 설정/권한 화면 이동·디스플레이 구성 변경은 닫는다. Option을 유지한 ⌘,로도 고정 없이 설정을 연다.
- 고정 상태에서 상단의 버튼을 제외한 제목·설명·전체 여백을 AppKit 기본 드래그로 이동한다. 컨트롤의 실제 bounds를 제외한다. 위치는 현재 표시 동안만 유지하며 재호출 때 커서 기준으로 돌아간다. 폴더 뒤로 버튼도 원형 Liquid Glass다.

## 최근 창·크기·배치

- 모든 앱의 열린 OS 창을 대상으로 하며 현재 창도 포함한다. iTerm 탭/분할을 별도 창으로 만들지 않는다. 닫힌 창·종료 앱은 정리하고 관찰하지 않은 과거 순위를 만들어내지 않는다.
- 최소 6개 용량·한 화면 두 줄. 자동은 가용 폭과 연속 앱 타일 크기로 배치하되 전체 창을 유지하고 두 줄 밖 항목은 세로 스크롤한다. 수동은 6 이상의 최대 개수, 제품 고정 상한 없이 실제 창 수까지만 표시한다.
- R57: 다른 데스크탑의 열린 창도 포함하며 **현재 데스크탑의 모든 창**을 시스템 강조색 배경으로 표시한다. 여러 화면이면 각 화면의 현재 데스크탑을 포함한다. 전역 최근 순서를 유지하며 데스크탑별로 재정렬하지 않는다.
- AX 목록 누락/시간 초과를 닫힘으로 간주하지 않는다. WindowServer 창 ID/PID와 AX 객체/닫힘 알림으로 유지·삭제를 판단한다. 처음 관찰한 다른 데스크탑 창의 제목이 없으면 대체 제목을 쓰고 선택 시 AX를 다시 조회한다.
- 정상 패널 760–1,040 × 620–720pt, 허용 비율 1.2–1.5, 화면 여백 24pt. 목표 1.45는 이번 나란한 배치에 맞춘 **에이전트의 구현 기본값**이며 이전 1.25 목표를 대체한다. 초광폭 화면에 따라 패널을 계속 늘리거나 면적 50%를 강제하지 않는다.
- 메뉴 4개 정사각 단위, 최근 창 최소 6개 단위의 공통 모듈과 간격 8pt를 사용한다. 창에 가로형 3개 × 두 줄 이상을 담는다. 실제 제목·작은 타일 가독성은 네이티브 검증 대상이다.
- 가용 영역이 작으면 메뉴를 생략하고 최근 창/등록 항목을 우선하는 작은 화면 배치를 사용한다. 512×420pt 패널도 들어가지 않으면 안내하고 메뉴 막대 설정을 제공한다. 전체 폰트를 통째로 축소하지 않는다.
- 호출 순간 커서 모니터의 visibleFrame을 기준으로 중심을 잡고 가장자리에서 위치만 보정한다. 열린 뒤 커서를 따라가지 않는다. 앱 문맥은 커서 아래 앱이 아닌 호출 직전 활성 앱이다.
- R56: 등록 선반은 본문 하단에 붙이고 실제 항목 수에 따라 일반 최대 3줄/작은 배치 최대 2줄 높이를 예약한다. 넘치는 항목은 선반 안에서 스크롤한다. 메뉴·최근 창 두 줄 높이와 타일 비율을 유지하고 남는 세로 여백의 30%를 그 위에 둔다. 이 비율은 초기 조정값이다.
- 목록·숫자·프로필 항목은 한 표시 동안 고정한다. 사용자의 명시적 프로필 선택과 메뉴 고정 편집만 즉시 반영한다. 재호출은 최신 순서와 스크롤 처음으로 시작한다.
- 고정 패널의 데스크탑 이동 시 현재 데스크탑 배경색만 갱신하며 타일 순서·크기·숫자는 변경하지 않는다.

## 앱별 메뉴

- 설정에서 실행 중 앱의 메뉴를 요청해 읽고 선택 등록하거나, 정확한 계층 경로를 직접 등록한다. 전체 앱 메뉴를 주기적으로 스캔하지 않는다. 새 등록 메뉴는 고정 상태를 기본값으로 한다.
- 런처에서 **성공한 실행만** 횟수와 최근 사용 시각을 로컬 저장한다. 다른 앱에서 직접 사용한 메뉴를 자동으로 추적하지 않는다.
- 초기 빈도 기준은 누적 3회, 기간별 감쇠 없음이다. 이는 에이전트의 조정 가능한 기본값이다. 고정·자주 사용 그룹은 수동 순서, 나머지는 최근 실행 순서다. 최근 순서를 직접 바꾸려면 고정한다.
- 실행은 호출 당시 앱/창으로 돌아가 정확한 현재 메뉴 경로를 다시 찾아 AXPress한다. 비활성·중복 경로·이름 변경·권한/응답 오류는 실패 안내, 자동 재실행 없음. 실패는 빈도에 넣지 않는다.
- 백그라운드 직렬 큐와 AX 메시지 시간 제한·조회 깊이/노드 수/시간 제한을 둔다. 초기 조회는 최대 1,800노드/깊이 12/약 3초 경계에서 중단한다. AX 단일 응답 지연까지 포함한 엄밀한 3초 전체 보장은 아니다.
- 동적 메뉴·서드파티 앱의 AX 노출·언어/문서 상태에 따른 차이가 있으므로 실제 Excel 이미지 용량 줄이기 명령을 별도 검증한다. 일부 메뉴는 원래 앱에서 한 번 연 뒤 불러오기가 필요할 수 있다.

## 등록 항목·프로필·폴더

- 앱·일반 폴더·다운로드·통합 휴지통을 수동 등록하고 순서를 바꾼다. 기존 목록/ID/이름/순서/폴더 방식은 ‘기본’ 프로필로 보존한다.
- 프로필별 등록 목록을 저장한다. **빈 프로필 추가**와 **현재 구성 복제**를 별도로 제공한다. 생성 즉시 새 프로필을 선택하며 공백 이름은 막는다. 선택·삭제를 제공하며 기본/마지막 프로필은 삭제하지 않는다. 수동 선택하면 자동 추종을 끈다.
- 집중 모드는 공개 SetFocusFilterIntent로 연결한다. 사용자가 macOS 집중 모드의 앱 필터에서 프로필을 지정하고 자동 추종을 켠 경우에만 따른다. 임의 집중 모드 이름 조회나 비공개 설정 읽기는 사용하지 않는다.
- 필터 없음/해제 시 마지막 수동 구성, 삭제된 프로필 ID는 기본/첫 구성으로 복귀한다. 앱 시작·깨우기와 명시적 자동 선택 때 현재 필터를 확인한다. 사용자 선택 시에만 표시 중 프로필을 바꾸고 자동 변경은 다음 호출에 반영한다.
- 일반 폴더는 항목별 ‘오버레이 탐색’/‘Finder 열기’. 탐색 시 하위 폴더·뒤로·새로고침·추가 날짜순/이름순·기본 연결 앱 실행. 추가 날짜가 없으면 생성일을 사용하며 재귀 색인·상시 폴더 감시는 하지 않는다.
- **휴지통은 Finder에서만 열기 가능**. 이유를 표시하며 다른 방식을 선택할 수 없다. Dock과 동일한 Finder 통합 trash 객체를 열고 로컬 ~/.Trash나 볼륨별 폴더로 대체하지 않는다. 외장 볼륨·되돌려 놓기·비우기는 Finder에 맡긴다. 전체 디스크 권한을 추가 요구하지 않는다.
- Dock에서 가져오기: Finder → 고정 앱 → 폴더 → 통합 휴지통 순서. 기존 중복 항목의 이름/방식 유지, Dock 밖 등록은 뒤에 보존. 비고정/최근 앱·최소화 창·웹 링크·개별 문서는 제외하고 건너뛴 수를 안내한다. Dock을 수정/재시작하지 않는다. 가져오기 시작 당시 프로필에 결과를 저장한다.

## 앱 수명·저장·기술 범위

- 로그인 자동 실행은 SMAppService.mainApp으로 사용자가 선택한다. 실제 상태·승인 대기·오류를 표시하고 사용자의 해제를 시작 시 임의로 되돌리지 않는다.
- 동일 사용자 한 인스턴스. 같은 버전/빌드는 기존 앱 유지, 다르면 정상 종료 후 가장 최근 실행 앱으로 전환하며 숫자의 대소는 따지지 않는다. 15초 시간 초과/종료 거부는 오류이며 강제 종료하지 않는다.
- 표시 버전·빌드·컴파일 결과 SHA-256을 시작 시 기록한다. 같은 경로 덮어쓰기/Finder 재열기/동시 실행/PID 재사용을 구별하며 잠금 파일을 지우지 않는다.
- Swift Package, AppKit NSPanel/NSGlassEffectView, SwiftUI, macOS 26 이상. 로컬 현재 아키텍처/ad-hoc 서명 개발 빌드이며 정식 OS·Intel·공증 배포 검증과 구별한다.
- 앱 출력은 동기화 폴더 밖 ~/Library/Developer/TileLauncher/build. 현재 Xcode beta를 프로젝트별 DEVELOPER_DIR로 지정하며 전역 개발 도구 설정은 바꾸지 않는다.
- 앱·창 관찰과 아이콘 캐시를 재사용한다. 썸네일·입력 문자 저장·메뉴 상시 수집 없음. 창 이력은 세션 메모리, 설정·프로필·등록 메뉴/횟수는 로컬 UserDefaults다.
- 모든 사용자 요청을 Markdown에 기록한다. 테스트/컴파일/패키징 성공을 실제 창 전환·Focus 연동·Liquid Glass·성능 검증과 혼동하지 않는다.
- Space 소속/선택 이동과 AX 창 ID 연결은 DesktopWindows.swift의 선택적 macOS 내부 함수로 보완한다. 공개 API 계약이 아니므로 App Store 지원을 전제하지 않으며 OS 업그레이드마다 확인한다. 함수/정보가 없으면 현재 여부를 추측하지 않고 공개 정보로 축소한다. 화면 녹화 권한은 추가 요구하지 않는다.
