# R210 · Dock 가져오기 미리보기·취소·되돌리기

후속 R212에서 모양·메뉴·등록 항목/프로필 전체가 탭별 저장/취소로 확정됐다. 아래는 R210 당시의 범위/검증 기록이다. 현재 Dock 확인과 되돌리기는 등록 편집본에서 처리하며 탭의 저장으로 실제 반영한다. [최종 저장 동작](1.9.2-tab-save-cancel.md).

2026-10-16. 사용자가 이번 변경도 마이너 대신 패치로 지정해, R209의 Help 클릭 수집 수정과 개발 소스1.9.2(41)에 포함한다. 공개·설치·실행본은1.9.1(40)이며 이번 수정본의 공증/설치/공개는 아직 하지 않았다.

## 범위와 동작

사용자는 Dock 가져오기가 즉시 저장되는 문제를 지적하고 확인 또는 저장 전 취소/되돌리기를 요청했다. 에이전트는 범위를 묻고 Dock 가져오기만 보호하는 기본 방향을 알렸다. 다른 설정의 실시간 저장을 없애는 변경으로 확대하지 않았다.

- 버튼은 Dock 목록을 읽고 대상 프로필·추가 수·적용할 최종 순서·건너뛴 항목 수를 미리 보여준다. 이 단계는 값만 만들고 프로필과 UserDefaults를 변경하지 않는다. 취소/창 닫기는 미리보기와 진행 중 읽기 결과를 버린다.
- 가져오기를 확인하면 처음 선택한 프로필에만 적용한다. 기존 항목의 이름/폴더 여는 방식은 유지한다. 미리보기 이후 해당 목록이 바뀌거나 프로필이 삭제되면 덮어쓰지 않고 다시 확인하도록 안내한다.
- 해당 프로필의 마지막 가져오기는 이전 목록·순서·여는 방식으로 되돌릴 수 있고 복원도 저장한다. 다른 프로필 선택이나 일반 설정 변경은 이 기록을 지우지 않는다.
- 가져오기 이후 같은 프로필의 항목을 편집하면 오래된 되돌리기가 그 편집을 지우지 않도록 해제한다. 완료 메시지도 프로필별로 보관한다. 되돌리기는 앱 실행 중에만 유지하며 기존1.9.1의 과거 가져오기를 소급 복원하지 않는다.
- 같은 목록/순서인 경우 변경 없음으로 끝난다. 읽기 실패·취소·미리보기에서 적용하지 않은 경우에는 기존 가져오기의 되돌리기 기록을 보존한다.

## 구현과 검증

- DeckCore의 DockImportChange가 미리보기 전후 목록과 대상 프로필을 보관한다. 적용은 before와, 되돌리기는 after와 현재 목록이 정확히 같을 때만 허용한다. SettingsStore는 확인 전 저장을 분리하고 늦은 읽기 결과/프로필 전환을 확인한다.
- XCTest201개와Python 배포 검사23개 통과. 순서·이름·폴더 방식 복원, 다른 프로필 거절, 미리보기/가져오기 뒤 편집 보존, 재가져오기 no-op/마지막 단계 복원을 포함한다. Help 표시 문구가 실제 메뉴 제목과 경로 두 방식으로 해석되면 저장하지 않는 회귀 검사도 포함한다.
- 고유 UserDefaults suite를 사용하는 네이티브 DockImportValidation에서 미리보기/취소 전후 저장 바이트 동일, 확인 저장/재로드, 수동 프로필 전환 후 원래 대상만 변경, 상태 메시지의 대상, 취소 후 이전 undo 유지, 복원 저장/재로드, 오래된 미리보기 거절과 추가 편집 뒤 undo 해제를 검사한다. 실제 사용자 설정이나 Dock을 변경하지 않는다.
- /tmp/tile-r209-validation에서 전체 앱 release 빌드, /tmp/tile-r210-products에1.9.2(41) 개발용 ad-hoc 앱을 만든다. 전체 비표시 네이티브 설정/오버레이 검사를 통과했고, 작은 미리보기에서 마지막 행이 잘리는 점은 목록 높이를 조절해 보완했다.
- 최종 UI 확인에서 실제 DockImportPreview와 SettingsView를 비표시 렌더링했고, 확인창 네 항목과 취소/가져오기 버튼 및 설정의 되돌리기 행이 잘리지 않는 것을 확인했다. 상단 네이티브 선택 탭이 검게 나오는 기존 비표시 합성 제한은 제품 변경과 구별한다. 로그는 /tmp/tile-r210-tests.log, /tmp/tile-r210-build.log, /tmp/tile-r210-previews.log, /tmp/tile-r210-dock-final.log다. 이미지는 dock-import-preview.png와 settings-dock-import-undo.png다.
