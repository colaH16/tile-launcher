# Tile Launcher 1.9.5 (55) · 공증 전 확인

후속 실환경 확인: 사용자는55의 타일/설정/핀 이동과7px 문턱은 동작하지만 빈 배경 이동은 실패한다고 보고했습니다. 아래는55 전달 당시의 동작 의도이며, 배경은56에서 직접 이동으로 수정합니다. 원형 버튼의 사각형 눌림 강조도 함께 수정합니다.

독립 샘플이 아니라 실제 Tile Launcher 앱입니다. Developer ID 서명·미공증 시험본이며, 공증과 GitHub 정식 배포는 사용자의 확인 뒤 진행합니다.

## 이번에 포함된 수정

- 메뉴·최근 창·등록 항목/폴더 타일과 설정/핀 버튼: 누른 곳에서 **7화면픽셀** 움직이면 창 이동으로 전환합니다. 문턱을 넘는 순간 처음 누른 지점부터의 전체 이동량을 반영하므로 커서와 잡은 지점이 어긋나지 않습니다.
- 문턱 전에는 원래 타일 안에서 놓으면 클릭합니다. 문턱을 한 번 넘으면 되돌아와도 타일을 실행하지 않습니다. 밖에서 놓거나 입력 중 타일이 사라져도 실행하지 않습니다.
- 빈 배경·타일 사이·섹션 내부 빈자리는 별도 문턱 없이 macOS 기본 배경 이동을 사용합니다. 타일의 문턱 이후 이동은 setFrameOrigin으로 처리하며, 입력 중 창 이동 플래그를 껐다 켜지 않습니다.
- 기존54시험본의 앱 설정 상태 수정도 포함합니다. AX 오류/불완전 구조는 비활성, 정상 전체 조회 미발견만 숨김으로 구분합니다.

7px는 물리 화면 픽셀입니다. Retina2배율에서는3.5pt이며 앱 UI/타일 배율과 독립적입니다. 시험 샘플의 숫자 입력 UI는 실제 앱에 추가하지 않았습니다.

## 실행과 확인

1. 기존 Tile Launcher를 메뉴에서 종료하고 ZIP을 압축 해제합니다.
2. `Tile Launcher.app`을 실행합니다. 두 버전을 동시에 실행하지 않습니다.
3. 설정 하단의 버전이 **1.9.5 · 빌드55**인지 확인합니다.
4. 타일 클릭/손떨림/7px 이상 끌기, 타일을 끈 뒤 배경 이동, 휠 스크롤/스크롤바, 최근 창 타일 우클릭 메뉴를 확인합니다.
5. 설정/핀 버튼 클릭과 드래그, 등록 폴더 열기/뒤로, 비활성 앱 설정 타일의 실행 차단도 확인합니다.

종료는 기존 Tile Launcher 메뉴의 종료를 사용합니다. 이전 설치본과 ZIP은 보존했습니다. 이번 전달에서는 이 Mac의 설치본을 교체하거나 앱을 재실행하지 않았습니다.

## 검증과 범위

217개 XCTest/배포 도구23개 검사, 실제 SwiftUI 오버레이41개 타일·버튼 영역의 화면 밖 입력 연결/7px 문턱 전 클릭·문턱 후 좌표 변화 및 클릭 취소 검사와 렌더링을 확인했습니다. Release에서는 임시 probe/진단 런타임을 포함하지 않습니다.

화면 밖 검사는 물리 마우스의 WindowServer 배경 이동 성공이나 실제 FPS를 입증하지 않습니다. 특히 타일은 앱이 좌표를 움직이고 배경은 macOS가 움직이므로 화면 가장자리/Spaces 등 시스템 창 배치 동작은 차이가 있을 수 있습니다.
