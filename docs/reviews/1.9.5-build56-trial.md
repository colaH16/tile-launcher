# Tile Launcher 1.9.5 (56) · 공증 전 확인

55의 실제 사용자 확인에서 타일/설정/핀의7px 이동과 클릭은 동작했지만 배경의 macOS 기본 이동은 실패했습니다.56은 **배경도 직접 이동으로 바꾸고 원형 버튼의 사각형 눌림 강조를 수정한** 실제 앱 시험본입니다.

- **빈 배경·섹션 내부 빈자리·타일 사이:** 첫 마우스 이동 이벤트부터 창을 직접 움직입니다. 별도의 거리 문턱이 없습니다.
- **타일·설정·핀:** 기존7화면픽셀 문턱과 원래 클릭 지점 기준 이동을 유지합니다. 문턱 전에 같은 타일에서 놓으면 클릭하며, 드래그로 전환되면 클릭을 실행하지 않습니다.
- **설정·핀·뒤로 버튼:** 눌림 강조도 원형으로 표시합니다.
- 우클릭·Control클릭·휠·스크롤바와 비활성 타일의 실행 차단은 유지합니다. 이전 앱 설정 상태 수정도 포함합니다.

기존 Tile Launcher를 종료한 뒤 ZIP의 `Tile Launcher.app`을 실행하고 설정 하단의 **1.9.5 · 빌드56**을 확인하세요. 배경의 작은 이동 → 타일 클릭/끌기 → 다시 배경 이동, 원형 버튼 클릭, 우클릭과 휠/스크롤바를 확인하면 됩니다.

Developer ID 서명·미공증 시험본입니다. 공증/정식 배포는 사용자 확인 뒤 진행합니다. 개발 Mac 설치/앱 재실행과 기존 전달 파일 교체는 하지 않았습니다. 시험용 숫자 입력/임시 상세 로그/probe는 제품에 넣지 않았습니다.

검증은218개 XCTest/배포 도구23개, 화면 밖 실제 오버레이 영역 연결·배경1물리픽셀 이동·타일7px·클릭 취소·원형 강조의 투명 모서리 검사와 렌더링, 서명 및 ZIP 재추출 검증입니다. 물리 마우스와 실제 FPS는 여기서 검증하지 않았습니다. 이동은 앱이 창 좌표를 갱신하므로 시스템의 화면 가장자리/Spaces 창 배치 동작과 차이가 있을 수 있습니다.
