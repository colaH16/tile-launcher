# A/B 드래그 샘플 전달 · R266 · 2026-10-17

사용자 요청에 따라 별도 AppKit 샘플 앱을 만들었다. 소스커밋0e6824352e8bd4b15744c4cf2d8b303c2a8c8a58 계열(정확한 전체 ID는동봉build.json), 앱0.1.0(1), ID dev.cola16.TileLauncher.DragSamples이며 제품1.9.5(54)와 독립이다.

A는 타일·설정·핀·배경 전체를 기본 배경 이동 범위로 허용한다. B는 메뉴/세션/등록앱의 세 직사각형 전체를 제외하고 바깥 여백/섹션 사이를 허용한다. B의 설정/핀은 세 직사각형 밖이므로 A처럼 이동·입력을 함께 시험한다. 타일 사이 여백은 해당 직사각형에 포함돼 B에서 이동 금지다.

클릭/0.55초 길게 누르기/우클릭 메뉴/핀 표시 토글을 제공하고 화면 아래 카운터로 결과를 표시한다. 실제 앱 실행/제품 설정 변경은 없다. 클릭은 놓을 때 실행하며6pt 이상 이동 또는 실제 창 frame 변화/이동 알림이 있으면 클릭과 미발생 길게 누르기를 취소한다.6pt는 샘플 입력 분류용이며 OS 기본 이동 문턱값을 변경하지 않는다. 길게 누른 뒤 추가 이동까지의 UX는 이후 제품 선택 사항이다.

performDrag/SwiftUI WindowDragGesture/수동 좌표 드래그를 쓰지 않고 isMovableByWindowBackground와 이벤트별mouseDownCanMoveWindow를 사용한다. 단일 NSView의 단색 그리기이며 블러/유리 효과/idle 폴링이 없다. 단발 타이머와 앱 로컬 마우스 모니터만 사용한다. 로그 최대5MiB, 비동기 쓰기, 이동 알림 최대10Hz다.

세 크기 영역 정책 검사, 화면 밖 AppKit 클릭/중복취소/실제 단발 타이머/미전달release취소/우클릭동작/핀토글 검사와 A/B PNG 렌더링을 통과했다. 최종 서명본에서도 검사를 통과했고 ZIP 재추출의 서명/영역검사를 확인했다. 잠긴 이 Mac에서 실제 물리 드래그 성공이나 네이티브 배경 이동과 클릭/길게의 실제 이벤트 전달을 검증했다고 주장하지 않는다. 최종 AppKit 검사 중sandbox_extension_issue_file_to_process 경고가 있었지만 검사와렌더링은exit0으로완료됐다.

Developer ID Application 서명/보안타임스탬프 완료·미공증 ZIP을 기존 상위 iCloud 동기화 폴더에 복사하고 해시를 확인했다. ZIP에는 앱/안내/소스/라이선스/A·B미리보기/build.json이 있다. 앱을 직접 열어 A/B 선택하며 CLI 플래그 불필요, 선택창 종료버튼/창닫기로 종료한다. 앱 메뉴에서 로그 폴더를 열 수 있다.
