# 1.9.3 고정·자동 수집 메뉴 구분과 정렬 · R214–R216

## 확정한 동작

사용자는 R215 시안3번을 선택했다. 설정 메뉴 목록은 고정과 자동 수집으로 나누고 고정0개에도 핀 안내·구분선을 남긴다. 순서 화살표는 고정에만 표시한다. 고정 하나면 위/아래 모두 비활성화하고, 여러 개면 실제 같은 앱의 고정 이동 대상이 있는 방향만 켠다.

고정은 수동 저장 순서로 먼저 표시한다. 나머지 전체는 메뉴 막대 관찰+Tile Launcher 실행의 누적 사용 횟수가 많은 순서로, 동률이면 마지막 사용 시각순으로, 다시 동률이면 저장 순서로 표시한다. 설정과 오버레이가 MenuCommand.ordered를 공유한다. 자동 수집의 자주/최근 구분은 글자로 알리되 그 사이에 별도 선은 두지 않는다.

기존 메뉴의 표시 기간·최근5개 보존·자주 사용 판정과 타일 크기/색은 유지한다. 오래된 누적 횟수만 높다는 이유로 보존 대상에서 빠진 항목을 되살리지 않는다. 설정 목록은 기존처럼 보존된 전체 항목을 보여준다. 사용 횟수/핀/UUID/언어별 경로를 임의로 수정하거나 마이그레이션하지 않는다.

## 원인과 수정

R214 캡처의 첫 메뉴는 누적4회라 자주 사용, 둘째는1회라 최근 사용이었다. 예전 버튼은 고정/자주 사용이면 켜졌지만 실제 이동은 같은 그룹에 상대가 있어야 했다. 첫 메뉴는 상대가 없어 버튼을 눌러도 움직이지 않았다. 최근 메뉴는 자동 최신순이라 버튼이 원래 꺼져 있었다. 저장/취소 병합 문제는 아니었다.

R216은 먼저 검토했던 기존 규칙 유지안을 대체한다. pinnedMoveTargets는 고정만 한 번 순회해 앱별 양방향 대상을 계산한다. 목록은 이 결과를 한 번 만들고 버튼마다 조회하며, 실제 moveCommand도 같은 계산을 쓴다. 고정 외 항목이나 다른 앱으로 이동하지 않고 잘못된 방향/큰정수도 거부한다.

메뉴 목록은 기존 List의 가용 높이/스크롤/메뉴 추가 버튼을 유지하고 고정 제목·빈 안내·Divider·자동 수집 제목을 행으로 넣는다. 전체 목록이 비어도 그룹 안내가 유지된다. 저장·변경 취소는1.9.2 편집본을 그대로 사용한다. 시안 전용 뷰와 실제 설정 화면은 구별하며 최종 검증은 실제 MenuSettingsView를 렌더한다.

## 검증

- XCTest213개, Python 배포 검사23개 통과. 추가4개 검사는 횟수 합산/고정 순서/다른 앱/자주·최근를 가로지르는 정렬, 동률 시각/안정 순서, 기존 보존 정책, 고정0·1·2개 양방향과 잘못된 입력을 확인한다.
- 기존 메뉴 재사용 회귀 검사의 예상 순서는 승인된 횟수순에 맞춰 수정했다. 다시 사용한 오래된 메뉴의 합산2회가 다른1회보다 앞선다.
- 네이티브 검사와 최종 렌더 결과는 아래에 완료 후 추가한다. 로그는 /tmp/tile-r216-tests.log, /tmp/tile-r216-build.log, /tmp/tile-r216-previews.log다.

## 버전과 범위

사용자 지정패치1.9.3(42)로 구현한다. 개발 앱은 /tmp/tile-r216-products/Tile Launcher.app이다. 현재 공개/설치/실행1.9.2(41)는 그대로이며 이번 시안 선택을 새 공증·GitHub 정식 공개·Mac 설치 요청으로 확대하지 않았다.

- 첫 비표시 검사에서 AppKit의 NSTableView 재진입 경고가 나타나, 이미 알고 있는 앱 ID는 설정 뷰 생성 시 초기화하도록 보완했다. 불필요하게 첫 레이아웃 도중 빈 그룹을 실제 목록으로 교체하지 않는다. 선호 앱이 없을 때의 기존 기본 선택 우선순위는 유지한다. 최종 빌드로 다시 검사한다.

- 선호 앱이 없는 상태도 포함해 초기 앱 목록 갱신은 취소 가능한 SwiftUI task에서 첫 테이블 레이아웃 이후 실행한다. 초기 AppKit delegate 안에서 행 그룹을 교체하지 않도록 하며, 사용자 선택과 메뉴 추가 요청은 기존대로 보존한다.

- 최종 검증 완료:1.9.3(42) 개발 빌드와 전체 네이티브 검사를 통과했다.
 고정0/1/2개 실제 MenuSettingsView에서 안내/구분선/화살표 상태와 목록·저장 버튼 배치를 확인했다. 실제 SettingsStore로 비고정 이동 차단, 고정 한 개 양방향 차단, 두 개 이동의 편집본 전용 변경·저장/취소·최신 사용 횟수/영구 저장도 확인했다.
- 최종 로그: /tmp/tile-r216-verified-previews.log. 행 종류를 안정된 ID의 단일 목록으로 구성해 그룹 변경과 명령 UUID를 함께 추적한다. 현재 macOS27.2 beta 비표시 렌더에는 NSTableView 재진입 경고가 일부 남는다. 종료0/레이아웃/저장 기능 검사와 구별하며 실제 전경 조작은 하지 않았다. 경고가 완전히 해결됐다고 주장하지 않는다.
- 최종 소스/테스트 해시는 검증 사본과 일치하고 개발 번들1.9.3/42, 실행 owner1.9.2를 확인했다. 전달 이미지: 시각화 폴더의 tile-launcher-1.9.3-menu-pins-0.png, -1.png, -2.png. 새 공증/공개/설치는 수행하지 않았다.
