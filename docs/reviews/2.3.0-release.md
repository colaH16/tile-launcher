# Tile Launcher 2.3.0(86) 정식 준비 기록

기준일: 2026-11-08 (Asia/Seoul). R394 정식 승인에 따라 새86 산출물을 준비하는 단계다. 기존 Claude 세션의 본 검수와 핵심 메뉴 보완 검수를 차단 사항 없이 완료했으며86 앱 빌드·서명·공증·게시 완료 기록이 아니다. 이번 정식 전환의 원격 main·태그·GitHub 릴리스·일반/@dev cask 변경은0건이다.

## 사용자 실기와 승인

공증2.3.0(85)의 회사 Mac 시험에서 사용자는 ①기본값 지정 동작 ②지정한 기본값의 macOS Focus 필터 새 선택 후보 제외 ③Work로 바꿨다가 다른 프로필로 바꾸면 등록 앱 프로필 복귀를 확인했다. 마지막은 직전 문맥의 macOS Focus 전환 관측이며 모든 앱·모드 조합의 보증이 아니다. 이 회사 회귀 시험은 통과로 업데이트한다. 사용자는 이어 Claude 검수와 정식 배포를 승인했다. R389의 과거 현상에 대한 기계적 근본 원인은 확정되지 않았으며 사용자 시험 성공과 구분한다.

## 정식86의 범위와 다음 절차

정식은2.3.0(86), MENU0/PROFILE0으로 새로 빌드한다. 85의 진단 메뉴·로거·관찰용 추가 Focus 조회와 Debug 검증 CLI는 정식에 포함하지 않는다. 기본값/수동선택 역할 분리·편집 대상 독립·이름 시트·Focus 새 후보 제외·기존 OS 관측 RAM 보존과 공통 eligibility는 그대로 유지한다. OS의 기존 연결을 자동 삭제하지 않는다.

## Claude 최종 검수와 남은 산출물 확인

실제 Claude는 기본값/수동 선택/Focus 역할, 설정 편집·저장/취소·복제 스냅샷, Option 첫 누름 위치, Help 클릭 지연 수집과 전역 모호성·Group/Button 경로, 메뉴 경로 UI 및 OFF 경계를 읽었고 릴리스 차단 사항을 찾지 못했다. 정적 검수이며 Claude가 테스트나 앱을 실행한 것은 아니다. 전체 원응답과 제한은 외부 검수 영수증으로 보존한다.

필터 없는 자동 선택이 수동 선택 대신 지정 기본값으로 돌아오는 의도된 변경은 공개 노트에 명시했다. 읽기 실패·앱 전환 시 보수적 미기록, Dock 가져오기 중 삭제 시 안내, 이전부터 있던 비동기 current 응답 순서 가능성은 신규 회귀로 확인되지 않았고 이번 제품 코드 수정 요청은 없었다.

86 메타데이터의 Python30은 통과했다. 최종 출하86에 대해서는 별도로 PROFILE0/MENU0·진단 및 Debug 문자열 제거, 새 기능 표시·Intent 메타데이터·버전86·Developer ID/CloudKit 권한·공증 티켓·Gatekeeper와 공개 ZIP/cask 해시를 검증한다. 이 기록 시점은 새 빌드 전이며 향후 실제 결과를 외부 영수증과 후속 문서 커밋으로 연결한다.
