# R212 · 탭별 저장·변경 취소

2026-10-16. 개발 소스1.9.2(41). 공개·설치·실행본은1.9.1(40)이며, 이번 수정본의 공증/공개/설치는 아직 하지 않았다. R209 Help 검색 클릭 수정, R210 Dock 보호와 함께 사용자 지정 패치에 포함한다.

## 확정된 동작

- 일반은 기존처럼 즉시 저장한다. 모양·메뉴·등록 항목/프로필에는 각자 저장·변경 취소 버튼을 둔다.
- 세 탭은 서로 다른 메모리 편집본을 사용한다. 편집 중에는 실제 설정/오버레이/자동 수집 환경을 바꾸지 않는다. 저장은 선택한 탭만 반영하고, 변경 취소는 해당 탭을 최신 저장값으로 복원한다. 탭을 옮겨도 다른 탭의 미저장 편집은 유지한다.
- 설정 창을 닫았다 다시 열어도 같은 앱 실행 중에는 편집본을 유지한다. 앱을 종료하면 미저장 편집은 남지 않는다. 창이 닫힌 동안에는 실제 설정 변화에 따른 편집본 갱신 작업을 중단한다.
- Dock 미리보기에서 가져오기를 확인하거나 되돌리기를 눌러도 등록 편집본만 바꾼다. 실제 적용에는 등록 탭의 저장이 필요하다. 메뉴 기간 입력의 별도 적용 버튼은 없애고 탭 저장에 포함한다.

## 실제 실행 상태와 병합

- SettingsStore 편집 사본은 UserDefaults 저장을 하지 않고 실제 앱 콜백을 갖지 않는다. 일반은 계속 실제 store를 사용하며, 탭 저장은 변경한 범위만 실제 store에 반영해 오래된 일반 값을 복원하지 않는다.
- 메뉴의 핀·심벌·아이콘/언어 연결·순서·제외 변경을 최신 메뉴에 합친다. 새 자동 수집 항목과 실제 사용 횟수/시각은 유지한다. 같은 메뉴가 편집 중 자동 수집됐으면 실제 항목의 UUID/기록을 보존해 중복 등록하지 않는다.
- 메뉴 삭제 시 저장 직전 확인된 언어별 전체 경로도 제외에 넣는다. 자동 수집 목록 비우기와 명시적 삭제/제외는 구별한다.
- 편집본에서 아이콘을 새로고침할 수 있고, 확인 중에는 저장을 막되 변경 취소는 가능하다. 취소한 비동기 결과가 편집본을 다시 바꾸지 않게 요청 세대를 무효화한다. 새 수동 메뉴의 실제 아이콘 수집은 탭 저장 후 시작한다.
- 등록 프로필은 서로 다른 프로필의 변경을 보존한다. 같은 목록/이름에 외부 변경이 겹치면 덮어쓰지 않고 최신 목록을 불러오도록 안내한다. 프로필 전환·삭제·수동 선택·집중 모드 설정도 저장 범위에 포함한다.
- 메뉴 병합은 기존 항목 위치를 인덱스로 찾아 전체 목록을 반복 탐색하지 않는다. 별도 폴링은 추가하지 않는다.

## 검증

- XCTest209개와Python 배포 검사23개 통과. 새 8개 병합 검사는 독립 모양 필드, 새 수집/사용 기록 보존, 삭제/순서, 동시 수동/자동 등록의 식별자 유지, 사용 기록으로 인한 가짜 변경 감지 방지, 제외 집합, 프로필별 병합과 충돌을 확인한다.
- 네이티브 SettingsEditingValidation은 고유 UserDefaults suite로 실제 저장을 검사한다. 편집/취소의 무저장, 일반 즉시 저장, 한 탭만 저장, 다른 탭 편집 보존, 최신 저장값 복원, 기간 입력 검증, 실제 콜백의 저장 후 실행, 동시 수집/사용 횟수와 언어별 삭제 제외, Dock 임시 반영, 창 비활성 중 갱신 중단/재개를 통과했다. 실제 사용자 설정은 바꾸지 않았다.
- 전체 앱 release 빌드와 비표시 네이티브 설정/오버레이 검사를 통과했다. 기본 일반 맞춤 콘텐츠580×918pt와 사용자 리사이즈/작은 화면 제한을 유지했고, 일반·모양이 기본 크기에서 스크롤을 필요로 하지 않는 검사도 통과했다. 하단 버튼과 목록이 겹치지 않는 것을 실제 렌더로 확인했다.
- 메뉴 아이콘 별도 검사도 통과했다. 음악 모의 앱의6개 심벌/언어별 경로/ID·핀 보존/삭제 제외·재추가·비동기 삭제 경합/원본 PDF·512px 비트맵을 확인했다. 사용자 앱을 실행하지 않았다.
- 단위/배포 로그 /tmp/tile-r212-tests.log, 빌드 /tmp/tile-r212-build.log, 전체 네이티브 /tmp/tile-r212-full-previews.log, 아이콘 /tmp/tile-r212-menu-icons.log. 개발용 ad-hoc 앱은 /tmp/tile-r212-products/Tile Launcher.app이다. 검증 소스/테스트 사본과 현재 저장소의 Swift 파일 해시도 일치한다.
- 이미지: settings-appearance-save-cancel.png, settings-menus-save-cancel.png, settings-registered-save-cancel.png. 선택된 네이티브 상단 탭이 비표시 합성에서 검게 보이는 기존 제한은 실제 저장/배치와 구별한다. 모양/메뉴 본문 이미지는 실제 SwiftUI 편집 화면을 직접 렌더했다.
