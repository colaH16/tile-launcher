# R229 · 아이콘 사전 읽기 구현

2026-10-16. 개발1.9.4(43)에 포함하며 공개·설치본1.9.3(42)는 바꾸지 않았다. [사전 측정](1.9.4-preload-performance.md) 이후 사용자는 아이콘 읽기만 승인했다.

## 범위

- 앱·폴더 등 기존 AppIconCache와 저장 메뉴 리소스의 SavedMenuImages를 utility 직렬 큐에서 채운다. 원본 NSImage/ICNS/PDF/PNG/SF Symbol 리소스 표현을 그대로 유지한다. raster 사전 그리기, 메뉴 정렬 캐시, 새 창/AX 조회, 설치 앱 전체 스캔은 추가하지 않는다.
- 현재 프로필은 시작 시 미리 읽고, 프로필 저장·수동 선택·집중 모드 변경·오버레이의 임시 프로필 전환도 준비한다. 프로필당 최초96개까지로 기존 캐시 용량을 넘는 추측 읽기를 제한한다.
- 현재 활성 앱은 시작/활성화 때, 새로 실행된 일반 앱은 실행 알림 때 준비한다. 실행 직후 일반 앱으로 아직 식별되지 않은 경우에도 후속 활성화와 기존 표시 로딩이 보완한다. 앱 설치·실행·등록 알림을 한 번 놓쳤다고 아이콘이 누락되는 구조가 아니다.
- 저장된 메뉴 이미지 목록만 비교한다. 수동/자동 추가 후 이미지 연결, 지연 리소스 검색 결과, 아이콘 변경과 수동 새로고침 완료 때 해당 이미지를 준비한다. 직접 Symbol 지정/아이콘 없음 항목은 리소스 읽기에서 제외한다. 기본 SF Symbol·단축키·텍스트 처리 경로는 바꾸지 않는다.
- 사용 횟수·최근 시각·핀 변화만으로는 이미지 준비 구독을 다시 실행하지 않는다. 메뉴 정렬은 기존 코드를 유지한다.

## 캐시와 경쟁 처리

- 앱 이미지 경로 캐시96개, 메뉴 이미지 캐시512개를 재사용한다. 메뉴는 내용 digest/형식/template의 기존 키로 이미지와 실패를 기억한다. 카탈로그 재스캔과 이미지 읽기는 구분되며 앱 업데이트 시 자동 리소스 재스캔을 추가하지 않았다.
- 큐에 같은 키가 대기 중이면 요청을 합친다. 실제 실행 직전에도 캐시를 확인하므로 대기 중 UI가 읽어 채운 이미지를 다시 읽지 않는다.
- 화면의 기존 getter는 그대로다. 미리 읽지 않은 항목, 새 앱, 캐시 회수, 대기 중 아직 완료되지 않은 이미지도 표시 시 읽는다. UI를 막아 utility 큐 완료를 기다리는 잠금은 두지 않는다. 양쪽이 거의 동시에 캐시를 놓치면 한 차례 중복 읽기는 가능하며, 정확히 한 번만 읽기 위해 UI를 대기시키지는 않는다.
- 새로고침은 리소스 메타데이터가 같더라도 기존 이미지 캐시를 비울 수 있으므로 MenuIconService 완료 콜백에서도 준비한다. 캐시 회수 후 활성화/새로고침/실제 표시가 다시 채운다.
- 종료 시 구독과 대기 작업을 취소한다. 이미 시작된 한 번의 파일/시스템 이미지 읽기는 끝날 수 있지만 사용자 설정이나 UI를 바꾸지 않는다.

## 검증

- Release 빌드 성공. 기존 XCTest215개/Python23개 통과, 비표시 전체 네이티브 검사 exit0.
- 주입한 이미지 캐시/로더로 새 앱, 연속 중복 요청, 등록 추가, 수동·자동 메뉴와 뒤늦은 이미지 연결, 이미지 변경, 같은 이미지 공유, 사용 횟수/핀 변화, 삭제, 회수 후 재요청과 종료 후 작업 차단을 확인했다.
- 실제 기본 백그라운드 로더는 임시 PNG8×8·없는 파일·설치되지 않은 합성 앱 URL로 확인했다. UI가 같은 캐시의 이미지를8×8 원래 크기로 읽고, 없는 이미지도 안전하게 기억하며, invalidate 후 같은 메타데이터를 다시 준비하는지 확인했다. 사용자 앱을 실행하거나 리소스/설정을 변경하지 않았다.
- 기존 앱 설정5회 중단 캐시, 전체 배경 드래그 제외44개, 연속 종료 유지, 작은 화면/등록39개 렌더도 통과했다. 기존 macOS27.2 beta 비표시 NSTableView reentrant 경고3건은 남는다.
- 추가 사전 읽기의 집 Mac 실제 첫 표시 단축량은 측정하지 않았다. 이전 계측의45종 최초 읽기약16ms를 모든 호출마다 절약한다고 주장하지 않는다. 이미 캐시된 반복 사용은 기존에도 빠르며 이번 구현은 비용의 시점을 앞당긴다.
