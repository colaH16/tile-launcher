# R236 · Messages 설정 탐지 opt-in 진단

2026-10-16. 사용자 “이응이응 ㄱㄱ 해줘” 승인으로 개발1.9.4(45)에 진단을 추가했다. 기존 R234 성공 캐시 유지도 포함한다. 다른 에이전트가 남긴 실환경 보고서와 기존 요청 번호는 보존하고 본 작업은 R236으로 구분한다.

## 구현

- AppSettingsDiagnostics: `--app-settings-log` 세션만 활성화. Messages 조회에는 requestID, 다른 앱 알림에는 식별자 없는 상태만 기록한다. 고정 enum/숫자/Boolean 및 고정 AX attribute 이름만 기록하며 AX 값/메뉴·대화·창 제목/임의 Error 설명은 쓰지 않는다.
- 고유 JSONL을 O_EXCL/O_NOFOLLOW/0600으로 생성하고 utility 직렬 큐에서 기록한다.4MiB 초과 시 log_limit을 남기고 멈춘다. 쓰기 실패는 진단만 중단하고 조회/UI를 실패시키지 않는다.
- ApplicationSettingsMenu: 시작/AX 읽기별 상태·예산/정상 미발견 사유/읽기 완료/취소·늦은 결과/캐시 게시·생략. 기존 nil/throw 결과는 그대로 실패1회를 소비하고 취소는 소비하지 않는다. 추측한 timeout 라벨은 붙이지 않는다.
- AppDelegate: workspace 알림과 refresh 호출 원인, UI 예약/숨김/입력 보류, build·refresh·present 시점의 실제 OverlaySnapshot.menuEntries 포함 여부를 기록한다. 표시 옵션/권한/현재 앱/서비스 캐시/스냅샷을 구분한다. 픽셀 렌더링 성공을 의미하지 않는다.
- 기본 실행에는 파일과 추가 AX 조회가 없다. 전환1회·총5회·AX300ms/전체2초와 didLaunch/didActivate의 기존 처리 순서는 보존했다. 메뉴 실행·프로필 저장·일반 UI에는 변경이 없다.

## 검증

- /tmp/tile-r235-build.log: Release 빌드 성공.
- /tmp/tile-r235-tests.log: XCTest215개·Python23개 통과.
- /tmp/tile-r235-native.log: 전체 비표시 검사 exit0. 새 진단 검사는 nil/throw/found의 구별,9개 합성 요청의 ID, 성공 캐시·5회 중단·취소된 성공 결과 폐기,100개 동시 이벤트의 JSONL 순서, 비밀 메뉴/오류 문자열·다른 앱 ID/PID 미포함,0600/O_EXCL,용량 제한을 검증했다.
- 이전 성공 유지/새PID/런처 초기화·아이콘 사전 읽기·드래그·연속 종료·설정 저장 취소·레이아웃 검사도 통과했다. 기존 macOS27.2 beta NSTableView 비표시 reentrant 경고3건은 그대로다.
- 이 Mac의 전경 앱/설치본을 조작하지 않았다. 진단용 미공증 ZIP 전달과 실제 집 Mac 재현을 구별한다. 공증/GitHub 게시를 수행하지 않는다.

실행 안내: ../app-settings-diagnostics.md. 배포 산출물 해시·서명 검증은 아래에 완료 후 추가한다.
