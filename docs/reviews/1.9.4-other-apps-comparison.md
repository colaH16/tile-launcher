# R245 · 다른 앱을 지정하는 비교 시험본

2026-10-17 / 1.9.4(50). 사용자는 과도한 개발을 중단하라고 요청한 뒤, build49의 신규 Messages 조회 순서를 확인하고 다른 앱도 시험하자고 요청했다. 미전달 survey/자동 집계 코드는 제외했으며 새 보고서 생성이나 상시 관찰을 추가하지 않았다.

## 변경 범위

- 기존 --app-settings-compare에 --app-settings-target BUNDLE_ID_OR_APP_PATH만 추가한다. 생략하면 Messages다. 잘못된 옵션은 AX/로그 시작 전에 exit2로 거부한다.
- 선택한 앱이 활성화돼야 실제7경로 비교를 시작한다. 대상 실행 전에는 대기하고 didLaunch/finishedLaunching을 함께 기록한다. 한 세션에 대상 하나만 읽는다.
- 기존 연속3회 전체 설정 탐지 성공/최대60초, 실행 대기 포함90초, 전환·종료·권한 취소 중단 규칙을 유지한다. native7경로/candidate matcher/제품 캐시는 바꾸지 않았다. CLI에는 대상/대기/종료 메시지를 추가했고 Control+C도 shutdown을 남긴다.
- 비교 로그에 선택한 appID/appName만 추가한다. 다른 앱은 익명 전환으로 남기며 일반 제품/기존 Messages 로그의 범위를 확대하지 않는다. 메뉴/대화/창/AX 반환 값은 저장하지 않는다.
