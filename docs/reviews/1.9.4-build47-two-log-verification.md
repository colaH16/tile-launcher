# R241 · 최근 두 원본 로그와 제품 재시도 수정 근거

2026-10-16. 사용자가 iCloud의 2026-10-16-build47-latest-two-comparison.zip과 다른 세션의 비교 분석을 제공했다. ZIP 원본을 직접 파싱해 검증했으며, 이어 R238에서 이미 승인한 제품 AX 오류 재시도를 진단 뒤 단계로 재개했다. 실제 Messages 조작은 하지 않는다.

## 원본 교차 확인

ZIP SHA256은 `f50f7ca85f52446fe5c4d694cd7c094e15b37a5d47c2f8d4f1c6debea12b3720`이며 CRC를 통과했다. ## 승인된 제품 수정 재개

사용자가 R238에서 선택한 AX 오류 후 최대2회 추가를 적용한다. 첫 실패의 완료 후0.4초, 다음 실패 완료 후0.8초다. 정상 응답의 미발견은 재시도하지 않는다. 프로세스 누적실패5회 상한, 성공 캐시 유지, 전환/종료/PID/권한 취소, 시작 완료 대기와 단일 진행 조회는 보존한다. 성공한 재시도는 제품 캐시와 기존 onChange 경로에 반영한다.

새 빌드48은 probe 없이 --app-settings-log로 제품의 retry_scheduled/retry_started/read_end/cache_published/snapshot을 확인한다. 요청별 ID와 묶음 retrySeriesID, 재시도 번호를 남긴다. 이번 두 원본 분석만으로 특정 간격의 성공을 보장하지 않고 사용자 실환경 확인을 거친다. 공증/정식 릴리스/개발 Mac 설치 교체는 하지 않는다.
