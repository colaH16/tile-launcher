# R383 · 메뉴 경로 캡션 구현·2.2.0(83) dev 시험 준비

기준일: 2026-11-06 (Asia/Seoul).

## 사용자 결정과 범위

- 첫 시안인 작은 부모 경로 위·기존 메뉴 이름 아래를 선택하고 진행을 지시했다.
- 일반 크기의 아이콘·저장 이미지·심볼·단축키 메뉴 타일에 적용한다. 이름12pt를 보존하고 경로9pt(75%)를 더한다. 타일 배율은 두 글자에 동일하게 적용한다.
- 저장된 경로만 사용하며 부모가 없거나 빈 성분이 있으면 추가 줄을 생략한다. 긴 경로는 가운데 생략하고 기존 전체 경로 툴팁을 유지한다.
- 작은 타일·텍스트 전용 glyph·레이블을 끈 기존 배치는 보존한다. Option 타일의 배지는 실제 너비를 확보해 캡션과 겹치지 않게 한다.
- 앱 메뉴 실행·수집·저장·드래그·Option 대상 영역은 바꾸지 않는다. 추가 AX 조회·캐시·지속 측정은 없다.
- 현재 단계는 공증된 2.2.0(83) @dev 시험본이다. 실제 사용자 확인 뒤 GitHub v2.2.0/정식 cask로 진행하며 별도 v2.1.11 태그·릴리스는 만들지 않는다.

## 구현과 상호 검토

실제 Claude 기존 대화(24d0061b-0998-45a6-89f5-c68c4655a01c)가 생산 코드를 작성했다. Codex는 독립 소스 리뷰·네이티브 렌더 검증·배포 준비를 분담했다. 초안에서 작은/텍스트 타일의 불필요한 footer 변경과 빈 부모 줄을 지적했고 Claude가 수정했다. 최종 읽기 전용 교차 검토에서 차단 이견은 없다.

- `MenuTileCaption.swift`: 저장 경로 변환과 경로/이름의 공통 caption.
- `Views.swift`: 일반 메뉴 타일에 caption 적용, Option 배지 너비 확보. 기존 실행 closure·식별자·대상 영역 보존.
- `MenuTileCaptionValidation.swift`/main 진입: DEBUG 전용 실제 caption·DeckView 렌더러 검증. 사용자 설정 대신 고유 임시 설정·합성 이미지와 출력 경로를 사용하고 실행 액션은0회다. 출하 Release에는 이 검증 코드와 인자가 들어가지 않는다.

## 완료한 자동 검증

최종 생산·검증 입력235개 SHA를 고정해 두 빌드 모드와 실제 출력 이미지를 확인했다.

- Swift 메뉴 진단 ON352/OFF344, Python30 테스트 모두 통과.
- 기존 Help deferred/Group 구조·Option 최초 위치·logger 정상/누락 인자 검증 통과.
- 새 native caption 검사 ON/OFF 통과: 실제 이름 픽셀 기준선 보존, 경로 위 행, 75% 크기·높이, 미상/빈 부모 줄 생략.
- 실제 DeckView 타일의 라이트/다크·1배/1.4배/좁은 폭6종을 렌더링했다. 저장 이미지·심볼·단축키·텍스트·부모 없음·고정/횟수·Option·큰 횟수와 small/legacy 대조군을 포함한다. root와 독립 Codex가 이미지에서 새 footer 겹침을 찾지 못했다.
- Release OFF 빌드와 진단 logger/role/structure 및 caption 검증 표식 제거 확인 통과. 검증 이후235개 입력의 SHA가 모두 동일하다.

이 검사는 사용자 앱 조작이나 실제 클릭 성공 시험을 대신하지 않는다. 실제 사용자 메뉴의 문맥·현지화/길이·커스텀 색 대비·VoiceOver·실제 선택 동작은 dev 시험에서 확인한다. Numbers TSV와 ChatGPT Browser→New tab 수집 성공은 앞선82에서 사용자가 확인한 결과다.
