# Tile Launcher 아이콘

사용자는 2026-10-12 마지막 ‘타일이 빠져나오는’ 안을 선택했다. 파란 계단형 바탕에서 초록 사각 타일이 오른쪽 위로 분리되는 두 요소다. Option 형태 안은 후보였으며 세 칸 격자 안은 Magnet을 연상시킨다는 이유로 교체했다.

- 최종 앱 아이콘: `AppIcon-source.png` → `../AppIcon.icns`.
- 메뉴 막대: 같은 두 요소의 `MenuBarTemplate.svg`, 실제 앱은 `BrandMark.swift`가 18pt 검정/투명 NSImage template로 그린다.
- `Concepts`의 두 PNG는 과거 비교안이며 앱에 패키징하지 않는다.
- built-in image_gen으로 생성했고 원본 alpha를 보존했다. `python3 scripts/build-icons.py`는 sips/iconutil로 16–1024px의 10개 macOS 표현을 ICNS에 담는다. 일반 빌드는 준비된 ICNS만 복사한다.
- 전통적인 다중 해상도 ICNS이며 Icon Composer의 계층형 아이콘이라고 설명하지 않는다.

## 최종 생성 프롬프트

Use case: logo-brand. Asset type: one minimal production-quality native macOS app icon concept for Tile Launcher. New alternative to an Option-key-like mark. Create a bold TWO-PIECE TILE-POPPING-OUT symbol, entirely front-on and flat, no perspective: a single large BLUE square tile occupying the lower-left of the central emblem, with its entire upper-right quarter cut away to form a clean stepped notch; and a small GREEN square tile slightly displaced up and to the right into open space beyond that notch, clearly separated by a generous clean negative-space gap. This must look like one tile being launched out of another, NOT a window grid. Exactly two colored shapes; the larger blue shape is one connected solid L-shaped stepped tile, never multiple panes. No diagonal ribbon, no Option key symbol, no arrow, no cursor, no rocket. Extremely simple silhouette recognizable at 18pt in monochrome. Nearly square inner corners. Clean moderately bright blue and emerald green, no gradients on the colored emblem. Center the emblem with generous breathing room on a soft off-white continuous rounded-square macOS app-icon body with extremely restrained native depth. Outer body centered in a 1024 by 1024 canvas at about 82% of canvas width. Genuinely transparent exterior, clean smooth anti-aliased edge with no ragged pixels or white specks and no external haze/shadow. No text, letters, four-pane windows, three-pane layout, Magnet-like window logo, decorative details or presentation layout. Only one app icon.

## Option 후보 프롬프트

Use case: logo-brand. Asset type: a distinctive minimal native macOS app icon for Tile Launcher, square 1024px composition, transparent exterior. Primary request: abandon all window-grid iconography. Create an abstract OPTION-KEY / LAUNCHING-A-TILE emblem. The emblem has exactly TWO separate pieces: a thick BLUE continuous angular ribbon that starts as a short horizontal segment at the upper LEFT, slopes diagonally down toward the lower middle, then turns into a horizontal segment extending toward the RIGHT at the bottom; and a SINGLE small GREEN square tile floating in the upper RIGHT above that bottom rail. It subtly evokes the macOS Option key symbol but is an original bold geometric mark. The blue diagonal ribbon and the isolated green square must be the entire emblem. The green square must NOT touch the ribbon. No enclosing inner frame. Place this original mark on a softly rounded off-white macOS app icon body with an extremely subtle native edge bevel and a clean mathematically smooth exterior alpha edge. Straight-on view, no perspective. Crisp, almost flat solids, clean moderately bright blue and emerald green. Generous breathing room. The mark must remain unmistakable when rendered monochrome at 18pt. No text, no letters, no four-pane or three-pane grid, no window layouts, no tall rectangle with two stacked rectangles, no Magnet-like icon, no Windows logo, no rocket, no sparkle, no heavy gradient, no chrome, no texture, no dramatic shadows. Only one app icon, not a presentation sheet. Outside the rounded app-icon body must be truly transparent.
